두 단계로 '만들고 → 비교하고 → 알려줍니다'

BOM을 만드는 것은 끝났고, 남은 일은 '저장 – 비교 – 판정 – 알림'의 매일 자동화입니다

3 시스템 구성

틀린 그림 찾기로 찾고, 신호등으로 알려줍니다

어제와 오늘 BOM을 나란히 놓고 달라진 곳을 찾은 뒤, '정상'과 '경고' 두 가지로 판정합니다

판정은 두 가지
정상
어제와 오늘 BOM이 같음 → 그대로 통과
경고
자재 · 수량 등이 어제와 다름 → 원인 역추적
찾는 변화 4가지
추가 없던 자재가 생김 · 삭제 있던 자재가 빠짐
변경 다른 자재로 바뀜 · 수량 개수가 달라짐
달라진 곳은 '경고'로 알리고, 원인까지 거꾸로 따라갑니다
