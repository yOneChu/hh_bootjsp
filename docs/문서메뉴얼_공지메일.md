# 팀 문서 매뉴얼(TeamDocs) 안내 메일 (발송용 초안)

> 아래 제목·본문을 그대로 메일에 붙여넣어 사용합니다.
> 대상 화면 : `readDBFile.html` — 좌측 사이드바 > **AI_도에인_정의서** (`/dash/viewLogic`)

---

## 1. 메일 제목

**권장안**

```
[안내] 팀 문서 매뉴얼(Docs) 화면 오픈 및 사용 방법 안내
```

**대안**

```
[수배로직설계팀] 로직 도메인 매뉴얼 화면 안내 — 문서 작성/조회 방법
[안내] 명세서·매뉴얼을 한 곳에서 — 팀 문서 화면 사용 안내
```

---

## 2. 메일 본문

```
안녕하세요, 수배로직설계팀입니다.

팀에서 사용하는 명세서·매뉴얼·업무 규칙을 한 화면에서 작성하고 공유할 수 있는
'팀 문서 매뉴얼' 화면을 안내드립니다.

작성한 내용은 DB에 저장되어 팀원 모두가 같은 내용을 보게 됩니다.
별도 설치 없이 브라우저에서 바로 사용하실 수 있습니다.


■ 접속 경로

  좌측 사이드바 > AI_도에인_정의서   (주소 : /dash/viewLogic)


■ 화면 구성

  ┌────────────┬──────────────────────────────┐
  │ 왼쪽 사이드바   │ 상단바 : 현재 위치 · 편집 · 새로고침 · 테마 │
  │ - 문서 검색    ├──────────────────────────────┤
  │ - 명세서 목록   │ 본문 (마크다운 문서)      │ 오른쪽 : 목차 │
  └────────────┴──────────────────────────────┘

  - 왼쪽 '명세서' 영역이 팀 공용 문서 목록입니다. (DB 저장 · 전원 공유)
  - 오른쪽 목차는 문서의 제목(h1~h3)을 자동으로 뽑아 표시하며, 클릭하면 해당 위치로 이동합니다.


■ 문서 보기

  1. 왼쪽 목록에서 문서 이름을 클릭하면 본문이 열립니다.
     - 대분류(DB 명세서 / API 정의서 / 기타 규칙)는 이름을 눌러 접거나 펼칩니다.
     - 이름 앞에 ▸ 표시가 있으면 하위 문서가 있는 항목입니다. 눌러서 펼쳐 주세요.
       (하위 문서는 단계 제한 없이 몇 단계든 만들 수 있습니다)

  2. 상단 검색창에 단어를 입력하면 문서 이름으로 즉시 걸러집니다.
     하위 문서가 검색어와 맞으면 상위 항목도 함께 펼쳐져 표시됩니다.

  3. 문서 이름 옆의 초록색 점은 '실제 DB와 연결된 문서'라는 표시입니다.
     본문 상단 배지로도 상태를 확인하실 수 있습니다.
       · DB 연결 (초록)  : DB에 저장되는 정식 문서
       · 목업 (주황)     : 아직 API가 연결되지 않아 내 브라우저에만 저장되는 문서
       · 읽기 전용 (자물쇠) : 조회만 가능하고 편집 버튼이 잠긴 문서

  4. 오른쪽 위 달/해 아이콘으로 다크 모드를 켜고 끌 수 있습니다.


■ 문서 작성 / 수정

  1. 문서를 연 뒤 오른쪽 위 [편집] 버튼을 누릅니다.
  2. 화면이 좌우로 나뉩니다. 왼쪽에 마크다운으로 작성하면 오른쪽에 결과가 바로 보입니다.
  3. 작성자 이름을 입력하고 [저장] 을 누릅니다. (단축키 Ctrl + S)
  4. 저장 즉시 DB에 반영되며, 다른 팀원도 새로고침하면 바로 확인할 수 있습니다.

  ※ 사용 가능한 마크다운 : 제목(#), 굵게/기울임, 목록, 체크박스, 표, 인용(>),
     코드 블록(``` ) — 코드 블록은 언어별 색상 강조가 적용됩니다.


■ 목록(메뉴) 직접 관리하기

  개발자에게 요청하지 않고 화면에서 바로 추가·수정·삭제할 수 있습니다.
  변경 내용은 DB에 즉시 저장됩니다.

  - 대분류 추가   : '명세서' 글자 오른쪽의 [폴더+] 버튼
  - 문서 추가     : 대분류 이름 오른쪽의 [ + ] 버튼
  - 하위 문서 추가 : 문서 이름 위에 마우스를 올리면 나타나는 [ + ] 버튼
  - 이름/아이콘 변경 : 마우스를 올렸을 때 나타나는 [연필] 버튼
       → 이름 입력창 다음에 아이콘 입력창이 이어서 뜹니다.
         아이콘 이름은 소문자와 하이픈만 사용합니다. (예: database, file-text, scroll-text)
         비워 두면 기본 아이콘이 적용됩니다.
  - 삭제         : 마우스를 올렸을 때 나타나는 [휴지통] 버튼
       → 하위 항목이 있으면 함께 삭제할지 한 번 더 확인합니다.
         본문 내용은 DB에 남아 있어, 같은 코드로 다시 만들면 그대로 복구됩니다.
  - 다시 불러오기 : 대분류 오른쪽의 [새로고침] 버튼
       → 다른 팀원이 방금 추가한 문서를 즉시 반영합니다.

  ※ 문서를 추가하면 SPEC00001 형식의 코드와 조회/저장 주소가 자동으로 부여되어,
     별도 설정 없이 바로 작성하실 수 있습니다.


■ 문서 조회 API 주소

  각 문서 제목 바로 아래에 '이 문서 조회 API' 카드가 표시됩니다.
  [복사] 버튼으로 전체 주소를 복사해 다른 시스템이나 AI 도구에서 그대로 호출할 수 있으며,
  응답은 마크다운 원문입니다.


■ 사용 시 참고사항

  - 팀과 공유할 문서는 반드시 왼쪽 '명세서' 영역에 작성해 주시기 바랍니다.
    사이드바 맨 아래의 [새 문서 작성] · [카테고리] · [내보내기/가져오기] 는
    본인 브라우저에만 저장되는 개인 메모 영역으로, 다른 팀원에게는 보이지 않습니다.
  - 같은 문서를 두 사람이 동시에 편집하면 나중에 저장한 내용으로 덮어써집니다.
    분량이 큰 문서는 하위 문서로 나누어 작성하시길 권장드립니다.
  - 편집 화면의 오른쪽 미리보기에서는 아이콘이 빈칸으로 보입니다. 저장 후 본문 화면에서 정상 표시됩니다.
  - 다크 모드 설정과 개인 메모는 사용 중인 브라우저에만 저장됩니다.
  - 목록이 기본값으로만 보이거나 '메뉴를 불러오지 못했습니다' 안내가 뜨면
    DB 연결 문제일 수 있으니 아래로 알려 주시기 바랍니다.


■ 문의

  화면 오류, 문서 목록 이상, 기능 개선 요청은 아래로 회신 부탁드립니다.
  수배로직설계팀 김영환 M

감사합니다.
```

## 3. 발송 전 확인 사항

- [ ] 접속 경로를 사내 도메인이 포함된 전체 URL 로 교체 (예: `https://<사내도메인>:8070/dash/viewLogic`)
- [ ] 사이드바 메뉴명 오타 확인 — 현재 `AI_도에인_정의서` (→ `AI_도메인_정의서`). 수정 후 발송하거나 본문 표기를 실제 화면과 맞출 것
- [ ] `PLM_DOC_MENU` 테이블 생성 스크립트가 운영 DB에 반영되었는지 확인
      (`src/main/resources/sql/PLM_DOC_MENU.sql`)
- [ ] 초기 대분류·문서 목록을 발송 전에 정리 (샘플/목업 문서 정리 여부)
- [ ] 문의처(담당자·연락처) 확정
- [ ] 수신자 범위 확정 (설계 담당자 / 유관 부서 포함 여부)
- [ ] 별도 사용 매뉴얼 문서를 첨부할지 결정 (`docs/문서매뉴얼_사용법.md` 는 현재 비어 있음)

## 4. 후속 안내용 (기능 추가 시 재사용)

기능이 추가될 때는 전체 안내 대신 아래 형식의 짧은 메일을 권장합니다.

```
제목: [안내] 팀 문서 매뉴얼 화면 기능 추가 - <기능명>

안녕하세요, 수배로직설계팀입니다.

팀 문서 매뉴얼 화면에 아래 기능이 추가되었습니다.

  - 기능 : <기능명>
  - 위치 : <화면 내 위치>
  - 동작 : <한 줄 요약>
  - 적용일 : YYYY-MM-DD

문의 사항은 회신 부탁드립니다.

감사합니다.
```
