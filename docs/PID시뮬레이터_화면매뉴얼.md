# PID 실행 시뮬레이터 — 화면 사용 매뉴얼

| 항목 | 내용 |
|---|---|
| 화면명 | PID 실행 시뮬레이터 |
| 접속 경로 | `/pid/pidSimulView` |
| 대상 데이터 | PLM PID 실행 결과 (`pidExecuteLineData`) · 호기 영업사양 |
| 문서 버전 | 1.0 (2026-10-07) |
| 작성 | 수배로직설계팀 |

---

## 1. 개요

호기와 PID 를 입력하면, 그 호기의 사양으로 PID 를 **실제로 한 줄씩 실행한 결과**를 보여주는 화면입니다.

- 각 라인이 **TRUE(조건 일치) / FALSE(불일치) / 미실행** 중 무엇이었는지
- 조건(SPEC = CON)별로 **왜 일치 · 불일치했는지** (호기 실제값과 비교)
- 결과(KEY = VAL)로 **어떤 값이 계산되었는지** (계산식에 대입된 값 포함)
- 마지막에 남은 **최종 OUTPUT**

을 한 화면에서 확인할 수 있습니다. PID 결과가 예상과 다를 때 원인 라인을 찾는 용도로 사용합니다.

---

## 2. 화면 구성

| 영역 | 설명 |
|---|---|
| 조회 조건 | 호기 · PID · testVersion · 추가 조건 · 특성코드 사전 |
| 툴바 | 라인 필터 · 최종 OUTPUT · CSV 저장 · 보기 옵션 · 검색 · 확대/축소 · 범례 |
| 결과 테이블 | PID 라인 목록. 화면 높이에 맞춰 이 영역만 스크롤됩니다 |
| 상세 패널 | 라인을 클릭하면 오른쪽에 열림. 조건 · 결과 · resultMap 상세 |

---

## 3. 조회

### 3.1 입력 항목

| 항목 | 필수 | 설명 |
|---|---|---|
| 호기 | 필수 | 예: `208223L01` |
| PID | 필수 | 예: `EL_PB186A01` |
| testVersion | 선택 | 체크하면 **테스트 버전 PID** 로 실행합니다 |
| 추가 조건 | 선택 | `추가 조건 ▾` 버튼으로 펼칩니다. `isfloor` · `floor` · `type` 값을 PLM 실행 API 에 그대로 전달합니다 |

입력 후 **Enter** 또는 **실행** 버튼을 누릅니다. 호기와 PID 가 비어 있으면 실행되지 않습니다.

### 3.2 실행 후 상단 안내

조회 조건 오른쪽에 아래 내용이 표시됩니다.

```
현재 표시: API 결과 (208223L01 / EL_PB186A01) · 2.3초 · 영업사양 412건
```

- **영업사양 N건** — 호기의 영업사양을 정상으로 읽은 건수입니다. 이 값으로 조건의 호기 실제값과 계산식 대입값을 보여줍니다.
- **영업사양 로딩 실패** (붉은 글씨) — PID 실행 결과는 정상이지만, 호기값 · 계산식 대입값 일부가 표시되지 않습니다.

### 3.3 주소로 바로 실행 · 공유

실행하면 주소창에 조건이 반영됩니다. 이 주소를 그대로 공유하거나 즐겨찾기하면, 열자마자 같은 조건으로 실행됩니다.

```
/pid/pidSimulView?hogi=208223L01&PID=EL_PB186A01&testVersion=&isfloor=&floor=&type=
```

## 4. 결과 테이블

### 4.1 컬럼

| 컬럼 | 설명 |
|---|---|
| `#` | 라인 번호 |
| `ADDR` | 라인 주소 |
| 결과 | `TRUE` · `FALSE` · `-`(미실행) |
| 조건 (SPEC = CON) | 라인의 조건. 칸 색으로 일치 · 불일치 표시 |
| 결과 (KEY = VAL) | 조건이 맞을 때 설정되는 값 |
| GOTO | 이동할 라인. `→ ADDR` 을 클릭하면 그 라인으로 이동합니다 |
| OUTPUT | **TRUE 라인만** 표시. 실제로 계산된 값 (아래 4.3) |
| REMARK | 비고 |

### 4.2 색 구분

| 표시 | 의미 |
|---|---|
| 초록 행 | TRUE — 조건이 모두 맞아 실행된 라인 |
| 빨강 행 | FALSE — 실행했지만 조건이 맞지 않은 라인 |
| 회색 행 | 미실행 — GOTO 등으로 건너뛴 라인 |
| 진한 초록 칸 | 해당 조건 일치 |
| 진한 빨강 칸 | 해당 조건 불일치 |

조건 칸에 마우스를 올리면 **호기 실제값**이 함께 보입니다. (예: `SPEC2 조건 불일치 · 호기값: 2200`)

### 4.3 OUTPUT 칸 읽는 법

| 표시 | 의미 |
|---|---|
| `KEY = 값` | 이 라인에서 KEY 에 저장된 최종 값 |
| `KEY = 값 (계산식)` | VAL 이 `[$ … $]` 계산식인 경우, `{변수}` 자리에 실제로 대입된 값을 채운 식을 괄호로 보여줍니다 |
| `CALL(PID명) → resultMap N건 보기` | 다른 PID 를 호출한 라인. 클릭하면 라인 상세에서 호출 후 resultMap 을 볼 수 있습니다 |
| `OUTPUT 선언 → 변수명` | OUTPUT 으로 선언된 변수 |

계산식의 변수는 **그 라인 실행 직전의 resultMap → 호기 영업사양** 순서로 찾습니다. 둘 다 없으면 `{변수}` 그대로 둡니다.

## 5. 툴바

| 기능 | 설명 |
|---|---|
| 필터 | `전체` · `TRUE` · `FALSE` · `실행된 라인`(TRUE+FALSE) · `미실행`. 버튼마다 건수 표시 |
| 최종 OUTPUT (N) | 마지막으로 실행된 라인 기준의 resultMap 을 상세 패널에 엽니다 |
| CSV 저장 | **지금 보이는 라인**(필터 · 검색 적용)을 CSV 로 저장. 엑셀에서 한글이 깨지지 않습니다. 파일명 `PID_<호기>_<PID>.csv` |
| 원본 컬럼 펼치기 | 기존 JSP 화면처럼 `SPEC1/CON1 …`, `KEY1/VAL1 …` 을 각각 컬럼으로 펼칩니다 |
| 빈 라인 숨기기 | 내용 · ADDR 이 없는 빈 라인을 숨깁니다 |
| 검색 | SPEC · CON · KEY · VAL · REMARK · ADDR · GOTO 대상. `/` 키로 바로 이동, Enter 로 결과로 이동 |
| 확대/축소 | 결과 테이블만 50% ~ 200%. 배율을 누르면 100% 로 복귀 (브라우저에 기억) |

CSV 에는 화면 컬럼 외에 **호기값**(조건 SPEC 의 호기 실제값) 컬럼이 추가로 들어갑니다.

## 6. 상세 패널

결과 테이블의 라인을 클릭(또는 Enter)하면 오른쪽에 열립니다.

| 구역 | 내용 |
|---|---|
| 머리 | 결과(TRUE/FALSE/미실행) · LINE · ADDR · GOTO · DOUID · REMARK |
| 조건 | SPEC(사양명) · CON · 일치 여부 · **원래값**(호기 실제값) |
| 결과 (KEY = VAL) | VAL 원문, 계산식이면 대입된 식(`= …`) |
| 이 라인 실행 후 resultMap | 이 라인 실행 직후의 전체 변수. 이 라인에서 설정한 KEY 는 강조 표시. 검색창으로 키 · 값 검색 |

- `▲` `▼` 버튼(또는 ↑ ↓ 키)으로 패널을 연 채 이전 · 다음 라인으로 이동합니다.
- 패널 왼쪽 경계를 끌어서 폭을 조절합니다 (브라우저에 기억).
- `Esc` 또는 `닫기 ✕` 로 닫습니다.

조건이 왜 불일치인지는 **CON(조건값)과 원래값(호기값)을 나란히 비교**하면 바로 확인할 수 있습니다.

---

## 7. 특성코드 사전

상단 **특성코드 사전** 버튼을 누르면 새 창으로 열립니다.

| 구역 | 내용 |
|---|---|
| 이 PID 에서 사용한 특성 | 현재 결과의 조건에 쓰인 특성코드 · 한글명 · 값 목록 · 사용 라인 수. 이 PID 에서 쓴 값은 강조 |
| 전체 특성코드 / 검색 결과 | 그 외 특성코드 (검색 결과는 최대 50건) |

- 특성코드 · 한글명 · 값 · 설명으로 검색합니다 (`/` 키).
- 시뮬레이터에서 다시 실행하면 사전도 자동으로 새 결과를 읽습니다. 수동으로는 **PID 결과 다시 읽기**.
- 팝업이 열리지 않으면 브라우저에서 이 사이트의 팝업을 허용해 주세요.

## 9. 제약 사항 및 참고

1. PID 실행은 서버가 **PLM(`plmpro.hdel.co.kr`)의 실행 API** 를 호출해 가져옵니다. PLM 접속이 안 되면 "결과가 없습니다" 로 표시됩니다.
2. 결과가 0건이면 호기 · PID 를 먼저 확인하고, 이상이 없으면 담당자에게 문의해 주세요.
3. 호기 영업사양을 읽지 못해도 실행 결과는 볼 수 있습니다. 다만 **호기값 · 계산식 대입값**이 표시되지 않습니다.
4. OUTPUT 칸은 **TRUE 라인만** 표시합니다. FALSE · 미실행 라인의 KEY = VAL 은 실행되지 않은 값입니다.
5. GOTO 로 이동할 라인이 필터로 숨겨져 있으면 필터가 자동으로 해제됩니다.
6. 확대 배율 · 상세 패널 폭은 **사용 중인 브라우저에만** 저장됩니다.

## 10. 활용 예시

**PID 결과가 예상과 다를 때 원인 라인 찾기**
실행 → `최종 OUTPUT` 에서 이상한 KEY 확인 → 검색창에 그 KEY 입력 → TRUE 라인의 OUTPUT 확인

**조건이 왜 안 맞았는지 확인**
필터 `FALSE` → 확인할 라인 클릭 → 상세 패널 조건에서 CON 과 원래값 비교

**계산식 값 검증**
OUTPUT 칸의 괄호 안 계산식 확인 → 대입된 값이 맞는지 영업사양과 비교

**다른 사람에게 같은 결과 보여주기**
실행 후 주소창의 URL 을 그대로 전달
