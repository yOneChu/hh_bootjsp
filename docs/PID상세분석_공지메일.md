# PID 상세 분석 화면 안내 메일 (발송용 초안)

> 아래 제목·본문을 그대로 메일에 붙여넣어 사용합니다.
> 첨부 : `PID상세분석_화면매뉴얼.md` (또는 PDF 변환본)

---

## 1. 메일 제목

**권장안**

```
[안내] PID 상세 분석 화면 오픈 및 사용 매뉴얼 배포
```

**대안**

```
[수배로직설계팀] 로직 PID Analytics 화면 안내 (매뉴얼 첨부)
[안내] PID 상세 분석 화면 — 최초 등록 조회 기능 추가 안내
```

---

## 2. 메일 본문

```
안녕하세요, 수배로직설계팀입니다.

PID 로직 데이터를 조건별로 조회할 수 있는 'PID 상세 분석' 화면을 안내드립니다.
사용 방법은 첨부 매뉴얼을 참고해 주시기 바랍니다.


■ 접속 경로

  /pid/searchPIDTotal  (사내망 · 좌측 사이드바 > PID 상세 분석)


■ 주요 기능

  1. 조건 조회
     - SPEC / CON / KEY / VAL / REMARKS 를 대상으로 최대 2개 조건을 조합해 조회합니다.
     - 두 조건을 '단독'(같은 번호에서 함께 만족) 또는 'AND'(각각 만족)로 결합할 수 있습니다.
     - PID GROUP 으로 PID 계열 자체를 단계별로 좁혀 조회할 수 있습니다.
     - 조회 전 검색식 미리보기로 조건 결합을 확인할 수 있습니다.

  2. 결과 확인
     - 헤더 클릭 정렬, 결과 내 재검색, 빈 컬럼 숨김, 페이지 단위 조회를 지원합니다.
     - 행에 마우스를 올리면 해당 행의 KEY - VAL 쌍이 요약 표시됩니다.

  3. 데이터 반출
     - Copy(클립보드) / CSV / EXCEL Download 세 가지를 제공합니다.
     - 10,000건 이상은 EXCEL Download 를 사용해 주시기 바랍니다.

  4. 최초 등록 조회
     - 특정 문구가 처음 등록된 PID, 버전, 행(NO), 등록일, 로직수정자를 확인합니다.
     - [조회] 버튼은 VAL1~VAL20 을, [전체컬럼대상조회] 버튼은 SPEC1~30, CON1~30,
       KEY1~20, VAL1~20 전체를 대상으로 검색합니다.
     - PID 와 검색 문구를 모두 입력해야 조회됩니다.


■ 사용 시 참고사항

  - 조건 01 을 REMARKS 로 선택하면 조건 02 는 사용할 수 없습니다. (입력이 자동 잠김)
  - 조건 02 의 값이 비어 있으면 해당 조건은 적용되지 않은 채 조회됩니다.
  - PID GROUP 은 PID-03 부터 순서대로 입력해야 다음 단계가 열립니다.
  - 최근 검색 이력과 화면 설정은 사용 중인 브라우저에만 저장됩니다.
  - EXCEL 다운로드 파일에 숫자 인식 관련 이슈가 있어 개선을 진행 중입니다.
    수치 데이터를 다루실 경우 Copy 후 엑셀에 붙여넣는 방식을 권장드립니다.


■ 문의

  화면 오류, 조회 결과 이상, 기능 개선 요청은 아래로 회신 부탁드립니다.
  수배로직설계팀 김영환 M

첨부 : PID 상세 분석 화면 사용 매뉴얼 (v1.0)

감사합니다.
```

## 3. 발송 전 확인 사항

- [ ] 접속 경로를 사내 도메인이 포함된 전체 URL 로 교체 (예: `https://<사내도메인>/pid/searchPIDTotal`)
- [ ] 첨부 파일을 PDF 로 변환할지 확인 (수신자 중 md 뷰어 미사용자 고려)
- [ ] 문의처(담당자·연락처) 확정
- [ ] 수신자 범위 확정 (설계 담당자 / 유관 부서 포함 여부)
- [ ] EXCEL 숫자 인식 이슈의 개선 일정이 정해졌다면 본문에 반영
