# PID 플레이그라운드 안내 메일 (발송용 초안)

> 아래 제목·본문을 그대로 메일에 붙여넣어 사용합니다.
> 첨부 : `PID플레이그라운드_화면매뉴얼.md` (또는 PDF 변환본)

---

## 1. 메일 제목

**권장안**

```
[안내] PID 플레이그라운드 화면 오픈 — DB 저장 없이 PID 로직을 고쳐서 바로 실행
```

**대안**

```
[수배로직설계팀] PID 수정 전 사전 검증 화면(PID 플레이그라운드) 안내 (매뉴얼 첨부)
[안내] PID 를 고치기 전에, 고친 결과를 먼저 확인할 수 있는 화면 오픈
```

---

## 2. 메일 본문

```
안녕하세요, 수배로직설계팀입니다.

PID 로직을 화면에서 직접 고친 뒤, DB 에 저장하지 않고 바로 실행해 볼 수 있는
'PID 플레이그라운드' 화면을 안내드립니다.

"이 조건을 바꾸면 결과가 어떻게 달라질까?" 를 PLM 수정 · 등록 전에 미리 확인하고,
디버거처럼 한 단계씩 실행하며 변수가 어디서 어떻게 바뀌는지 추적할 수 있습니다.
사용 방법은 첨부 매뉴얼을 참고해 주시기 바랍니다.


■ 접속 경로

  /simulplay/pidSimulPlayGround  (사내망)


■ 사용 순서

  ① PID · 버전 선택 → [불러오기]
  ② 표에서 SPEC / CON / KEY / VAL 수정 (라인 추가 · 복제 · 삭제 · 순서 변경 가능)
  ③ 공사번호 입력 → [실행] (Ctrl+Enter)
  ④ 라인별 TRUE / FALSE 와 그 시점의 값을 확인, F10 으로 한 단계씩 추적


■ 주요 기능

  1. 엑셀처럼 편집
     - 셀 직접 수정, 복사 · 붙여넣기, 오른쪽 클릭으로 라인 추가 · 복제 · 삭제
     - 수정한 칸은 표시되고, 마우스를 올리면 DB 원본 값을 보여줍니다.

  2. 실시간 실행
     - 스위치를 켜 두면 고칠 때마다 자동으로 다시 실행해 결과가 바로 반영됩니다.

  3. 단계별 디버거
     - 실제 실행 순서대로 단계 이동 (F10 다음 / Shift+F10 이전)
     - 조건마다 '그 시점의 실제 값' 과 CON 을 비교해 일치 · 불일치를 표시
     - 라인마다 바뀐 값(이전 → 이후), 감시할 변수 고정 기능 제공

  4. 결과 확인 탭
     - 라인별 결과 / 라인 상세 / 변수 / 최종 OUTPUT / 최종 영업사양 / 하위 PID

  5. 변경 내역 정리
     - DB 원본 대비 수정 내용을 '라인 · 칸 · 원본 → 수정' 으로 정리해
       PLM 반영 시 참고할 수 있습니다.

  6. 공유
     - 주소를 공유하면 같은 PID · 공사번호로 바로 실행됩니다. (수정 내용은 주소에 포함되지 않음)


■ 사용 시 참고사항

  - 이 화면에서 고친 내용은 DB 에 저장되지 않습니다.
    실제 반영은 반드시 PLM 에서 진행해 주세요.
  - 수정 내용은 어디에도 저장되지 않아 새로고침하면 사라집니다.
    남겨 두려면 편집 표를 복사(Ctrl+C)해 엑셀에 보관해 주세요.
  - CALL 로 호출되는 하위 PID 와 전처리 PID 는 항상 최신 DB 버전으로 실행됩니다.
    수정본은 불러온 PID 에만 적용됩니다.
  - JAVA 방식 PID 는 편집할 수 없으며, 실행 결과만 확인 가능합니다.
  - 기존 'PID 실행 시뮬레이터'(/pid/pidSimulView)는 현재 DB 로직의 실행 결과 확인용,
    'PID 플레이그라운드' 는 수정안 사전 검증용으로 구분해 사용하시면 됩니다.


■ 문의

  화면 오류, 실행 결과 이상, 기능 개선 요청은 아래로 회신 부탁드립니다.
  수배로직설계팀 김영환 M

첨부 : PID 플레이그라운드 화면 사용 매뉴얼 (v1.0)

감사합니다.
```

## 3. 발송 전 확인 사항

- [ ] 접속 경로를 사내 도메인이 포함된 전체 URL 로 교체 (예: `https://<사내도메인>/simulplay/pidSimulPlayGround`)
- [ ] 좌측 사이드바 메뉴에 등록할지 확인 (현재 사이드바에 링크 없음 — 등록 시 본문에 메뉴 위치 추가)
- [ ] 편집 표 라이브러리(Handsontable)를 `cdn.jsdelivr.net` 에서 받으므로, 수신자 PC 에서 해당 주소 접근 가능한지 확인
- [ ] 예시 링크가 필요하면 본문에 추가 (예: `/simulplay/pidSimulPlayGround?pid=D375A&project=206663L01`)
- [ ] 첨부 파일을 PDF 로 변환할지 확인 (수신자 중 md 뷰어 미사용자 고려)
- [ ] 문의처(담당자·연락처) 확정
- [ ] 수신자 범위 확정 (PID 설계 담당자 / 유관 부서 포함 여부)
