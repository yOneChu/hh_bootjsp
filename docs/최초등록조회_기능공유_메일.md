# 최초 등록 조회 기능 공유 메일 (발송용 초안)

> 아래 제목·본문을 그대로 메일에 붙여넣어 사용합니다.
> 대상 화면 : PID 상세 분석 (`/pid/searchPIDTotal`)
> 참고 문서 : `docs/PID상세분석_화면매뉴얼.md`

---

## 1. 메일 제목

**권장안**

```
[안내] PID 상세 분석 화면 '최초 등록 조회' 기능 오픈
```

**대안**

```
[수배로직설계팀] 문구가 처음 등록된 PID·버전·담당자를 찾는 기능 안내
[안내] 로직 PID Analytics — 최초 등록 조회 기능 추가 (VAL / 전체 컬럼)
```

---

## 2. 메일 본문

```
안녕하세요, 수배로직설계팀입니다.

PID 상세 분석 화면(/pid/searchPIDTotal)에 '최초 등록 조회' 기능을 오픈하여 안내드립니다.

특정 문구가 언제, 어느 PID의 몇 번째 버전에, 누가 처음 등록했는지를
한 번의 조회로 확인할 수 있는 기능입니다.
("이 사양 문구가 원래 언제부터 들어가 있었는지" 를 추적하실 때 사용하시면 됩니다)


■ 기능 개요

  입력한 PID 안에서 찾고자 하는 문구를 포함한 데이터를 모두 훑어,
  그 문구가 가장 먼저 등록된 버전을 찾아 팝업으로 보여줍니다.

  결과로 확인할 수 있는 항목
    - PID          : 문구가 처음 등록된 PID
    - 버전          : 그 PID의 몇 번째 버전인지
    - 행 (NO)       : 해당 버전에서 문구가 위치한 행 번호
    - 등록일        : 해당 버전의 등록 일시 (YYYY-MM-DD HH:MI:SS)
    - 로직수정자     : 그 버전을 등록·수정한 담당자 이름
    - PID 명 / REMARKS : 해당 버전의 명칭과 비고


■ 사용 위치

  /pid/searchPIDTotal 접속 → 화면 상단 '도움말' 바로 아래
  보라색 아이콘의 [최초 등록 조회] 패널을 클릭하면 펼쳐집니다.
  (자주 쓰는 기능이 아니라 기본은 접힌 상태입니다)


■ 사용 방법

  1) PID 입력            : 조회할 PID 명칭을 입력합니다.          (필수)
  2) 찾고자 하는 문구 입력 : 예) DOOR OPEN TIME                    (필수)
  3) 아래 두 버튼 중 하나를 선택합니다. (입력란에서 Enter 키로도 조회됩니다)

     [조회 (VAL 컬럼)]   VAL1 ~ VAL20 만 대상으로 조회합니다.
                        → 값(VAL)에 들어간 문구를 찾을 때 사용하며, 가장 빠릅니다.

     [전체컬럼대상조회]   SPEC1~30 · CON1~30 · KEY1~20 · VAL1~20 을 모두 조회합니다.
                        → 문구가 어느 항목에 들어 있는지 모를 때 사용합니다.

  ※ PID 와 문구는 둘 다 필수입니다. 하나라도 비어 있으면 안내 메시지가 표시됩니다.
  ※ [지우기] 버튼으로 입력값을 한 번에 비울 수 있습니다.


■ 결과 팝업 구성

  1. 요약 타일 (상단 5개)
     PID · 버전 · 행(NO) · 등록일 · 로직수정자를 한눈에 보여줍니다.
     같은 버전에서 여러 행이 걸린 경우 행 번호는 "12 외 2개" 형태로 요약됩니다.

  2. 조회 조건 요약
     검색 문구 / 검색 대상 컬럼 / PID 조건 / PID 명 / REMARKS 를 함께 표시합니다.

  3. 같은 버전에서 걸린 행
     최초 등록 버전 안에서 문구가 걸린 행이 2건 이상이면 목록 표가 추가됩니다.
     행(NO) 오름차순으로 정렬되며, 대표 행에는 ★ 표시가 붙습니다.
     (표에는 최대 200건까지 표시됩니다)

  4. 결과 복사
     팝업 하단 [결과 복사] 를 누르면 PID · 버전 · 행(NO) · 등록일 · 로직수정자 ·
     PID명 · REMARKS 가 엑셀에 바로 붙여넣을 수 있는 형태로 복사됩니다.

  ※ 팝업은 ESC 키, 바깥 영역 클릭, [닫기] 버튼으로 닫을 수 있습니다.


■ 조회 기준 (판정 방식)

  - 입력한 문구가 포함된(부분 일치) 데이터를 대상으로 합니다.
    문구 전체가 정확히 일치하지 않아도 되며, 입력한 그대로 검색됩니다.
  - 등록일이 가장 빠른 버전을 '최초 등록'으로 판정합니다.
    해당 버전에서 걸린 행은 모두 결과에 포함됩니다.
  - 작업 이력상 유효하지 않은 버전(VERSION = -1)은 조회 대상에서 제외됩니다.
  - 로직수정자는 등록자 사번을 사용자 정보와 연결해 이름으로 표시합니다.
    사용자 정보가 없는 예전 데이터는 '—' 로 표시됩니다.


■ 사용 시 참고사항

  - 결과가 나오지 않을 경우, 문구를 더 짧게 입력하거나 PID 명칭이 정확한지
    확인해 주시기 바랍니다. (공백·대소문자가 다르면 검색되지 않을 수 있습니다)
  - [전체컬럼대상조회] 는 검색 범위가 넓어 [조회] 대비 시간이 더 소요됩니다.
    값(VAL)에서 찾는 것이 확실한 경우에는 [조회] 사용을 권장드립니다.
  - 화면 하단 '도움말' 항목에도 동일한 안내가 정리되어 있습니다.


■ 문의

  조회 결과 이상, 기능 개선 요청은 아래로 회신 부탁드립니다.
  수배로직설계팀 김영환 M

감사합니다.
```

## 3. 짧은 버전 (사내 메신저·공지 게시판용)

```
[PID 상세 분석] '최초 등록 조회' 기능이 오픈되었습니다.

  · 위치   : /pid/searchPIDTotal → 상단 [최초 등록 조회] 패널
  · 기능   : 입력한 PID 안에서 특정 문구가 '처음 등록된' 버전을 찾아
             PID · 버전 · 행(NO) · 등록일 · 로직수정자를 팝업으로 표시
  · 사용법 : PID + 찾을 문구 입력 후
             [조회] = VAL1~VAL20 대상 / [전체컬럼대상조회] = SPEC·CON·KEY·VAL 전체 대상
  · 결과는 [결과 복사] 로 엑셀에 바로 붙여넣을 수 있습니다.

문의는 수배로직설계팀 김영환 M 으로 부탁드립니다.
```
