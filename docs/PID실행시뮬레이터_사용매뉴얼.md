# PID 실행 시뮬레이터 — 화면 사용 매뉴얼

| 항목 | 내용 |
|---|---|
| 화면명 | PID 실행 시뮬레이터 (V2) |
| 접속 경로 | `/pid/pidSimulView` |
| 대상 데이터 | PLM PID 실행 결과 (`pidExecuteLineData`) · 호기 영업사양 (`getSalesInfo`) |
| 문서 버전 | 1.0 (2026-10-01) |
| 작성 | 수배로직설계팀 |

---

## 1. 개요

호기와 PID를 넣으면 **그 PID가 라인별로 어떻게 실행됐는지** 표로 보여주는 화면입니다.
라인마다 어떤 조건이 맞았는지, 어떤 값이 만들어졌는지, 다음에 어디로 이동했는지를 한눈에 볼 수 있습니다.

이럴 때 사용합니다.

- PID 결과가 예상과 다를 때 **어느 라인에서 갈렸는지** 찾기
- 라인이 FALSE 인데 **호기의 실제 사양값이 무엇이었는지** 확인하기
- 계산식(`[$ … $]`)에 **실제로 어떤 값이 대입됐는지** 확인하기
- 실행 결과를 **CSV(엑셀)** 로 저장해 공유하기

> 이 화면은 PLM 의 PID 실행 결과를 **보여주기만** 합니다. PID 로직을 수정하는 기능은 없습니다.

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ① 조회 조건  호기 [      ] PID [        ] □testVersion [실행] [추가 조건▾] │
│                                         [특성코드 사전]   ⑤ 상태 표시      │
├──────────────────────────────────────────────────────────────────────────┤
│ ② 툴바  [전체|TRUE|FALSE|실행된 라인|미실행] [최종 OUTPUT] [CSV 저장]       │
│         □원본 컬럼 펼치기 □빈 라인 숨기기 [검색……]   [− 100% +] 범례       │
├───────────────────────────────────────────────┬──────────────────────────┤
│ ③ 결과 테이블                                  │ ④ 라인 상세 패널          │
│  # │ADDR│결과 │조건(SPEC=CON)│결과(KEY=VAL)│…  │  조건 / 현재값            │
│  1 │    │TRUE │ …            │ …           │   │  결과 KEY = VAL           │
│  2 │    │FALSE│ …            │ …           │   │  실행 후 resultMap        │
└───────────────────────────────────────────────┴──────────────────────────┘
```

| 번호 | 영역 | 언제 보이나 | 하는 일 |
|---|---|---|---|
| ① | 조회 조건 | 항상 | 호기 · PID 입력, 실행, 추가 조건, 특성코드 사전 열기 |
| ② | 툴바 | 실행 후 | 필터, 최종 OUTPUT, CSV 저장, 검색, 확대/축소 |
| ③ | 결과 테이블 | 실행 후 | PID 한 라인 = 표 한 줄 |
| ④ | 라인 상세 패널 | 라인 클릭 시 | 선택한 라인의 조건 · 현재값 · 결과 · resultMap |
| ⑤ | 상태 표시 | 실행 후 | 걸린 시간, 영업사양 로딩 결과 |

## 3. 빠른 시작 (4단계)

1. 브라우저에서 `/pid/pidSimulView` 를 엽니다.
2. **호기**와 **PID**를 입력합니다. 예) 호기 `208223L01`, PID `EL_PB186A01`
3. **실행** 버튼을 누르거나 `Enter` 를 누릅니다.
4. 결과 표에서 초록색(TRUE) 라인과 **OUTPUT** 칸을 확인합니다. 궁금한 라인은 클릭하면 오른쪽에 상세가 열립니다.

> 실행 시 PID 결과와 **호기 영업사양을 함께** 받아옵니다. 영업사양 조회 때문에 **15초 안팎** 걸릴 수 있습니다.
> 같은 호기로 다시 실행하면 영업사양은 다시 받지 않아 빨라집니다.

## 4. 조회 조건

| 항목 | 필수 | 설명 | 예시 |
|---|---|---|---|
| 호기 | ● | 시뮬레이션할 호기 번호 | `208223L01` |
| PID | ● | 실행할 PID 이름 | `EL_PB186A01`, `CAL_B182A01_RAIL` |
| testVersion | | 체크하면 **테스트 버전 PID** 로 실행 | 체크박스 (실행 버튼 왼쪽) |
| isfloor | | 추가 조건 (PLM PID 실행 API 에 그대로 전달) | 보통 비워 둠 |
| floor | | 추가 조건 (PLM PID 실행 API 에 그대로 전달) | 보통 비워 둠 |
| type | | 추가 조건 (PLM PID 실행 API 에 그대로 전달) | 보통 비워 둠 |

- 호기 또는 PID 가 비어 있으면 *"호기와 PID는 필수입니다."* 안내가 뜨고 실행되지 않습니다.
- isfloor · floor · type 은 **추가 조건 ▾** 버튼을 눌러야 보입니다. 실행하면 다시 접힙니다.
- isfloor · floor · type 이 어떤 값을 받는지는 PID 마다 다르므로, 필요하면 해당 PID 로직 담당자에게 확인하세요.

## 5. 상태 표시 (화면 오른쪽 위)

실행이 끝나면 오른쪽 위에 이번 조회 정보가 표시됩니다.

```
현재 표시: API 결과 (208223L01 / EL_PB186A01) · 12.4초 · 영업사양 1023건
```

| 표시 | 의미 |
|---|---|
| `API 결과 (호기 / PID)` | 지금 표에 나온 결과의 조회 조건 |
| `N초` | 실행 버튼을 누른 뒤 결과가 나오기까지 걸린 시간 |
| `영업사양 N건` | 호기 영업사양을 정상으로 불러옴 |
| <span style="color:#d64545">**영업사양 로딩 실패 — …**</span> (빨간 글씨) | 영업사양을 못 불러옴 → **현재값 · 계산식 값 일부가 표시되지 않음** |
| <span style="color:#d64545">**영업사양 0건 — …**</span> (빨간 글씨) | 영업사양이 비어 있음 (호기 번호 확인) |

> 빨간 글씨가 보이면 PID 결과 자체는 정상이지만, **현재값 · 계산식 치환값을 믿으면 안 됩니다.** 다시 실행해 보세요.

## 6. 결과 테이블 읽는 법

### 6.1 컬럼

| 컬럼 | 내용 |
|---|---|
| `#` | 라인 번호 |
| `ADDR` | 라인 주소(레이블). GOTO 가 이 값으로 이동합니다 |
| `결과` | `TRUE` 조건 만족 · `FALSE` 조건 불만족 · `-` 실행되지 않음 |
| `조건 (SPEC = CON)` | 비교한 특성코드(SPEC) 와 조건값(CON). 칩 하나 = 조건 하나 |
| `결과 (KEY = VAL)` | 조건이 맞으면 만들어지는 변수(KEY) 와 값/식(VAL) |
| `GOTO` | 다음에 이동할 ADDR. **클릭하면 해당 라인으로 이동** |
| `OUTPUT` | TRUE 라인에서 실제로 만들어진 값 |
| `REMARK` | 라인 설명 |

왼쪽의 `#` · `ADDR` 컬럼은 고정되어 있어, 표를 오른쪽으로 스크롤해도 항상 보입니다.

### 6.2 색상

| 표시 | 의미 |
|---|---|
| 연한 **초록** 줄 | TRUE — 라인의 조건이 모두 맞아 결과가 만들어짐 |
| 연한 **빨강** 줄 | FALSE — 실행됐지만 조건이 맞지 않음 |
| **회색** 글자 줄 | 미실행 — GOTO 등으로 건너뛰어 실행되지 않음 |
| **초록** 칩 | 그 조건 하나가 일치 |
| **빨강** 칩 | 그 조건 하나가 불일치 |

> FALSE 라인에서 **빨간 칩**이 그 라인을 막은 조건입니다.

### 6.3 조건 칩에 마우스 올리기 → 호기값 확인

조건 칩(또는 원본 컬럼 모드의 SPEC/CON 셀)에 마우스를 올리면 툴팁에 **이 호기의 실제값**이 나옵니다.

```
SPEC1 조건 불일치 · 호기값: KS190328
```

조건값(CON)과 호기값을 바로 비교할 수 있어, FALSE 원인을 다른 화면에서 찾지 않아도 됩니다.

### 6.4 OUTPUT 칸의 표시

| 표시 | 의미 |
|---|---|
| `KEY = 값` | 그 라인에서 만들어진 변수와 값 |
| `CALL(하위 PID) → resultMap N건 보기` | 다른 PID 를 호출한 라인. 만들어진 값은 라인 상세의 resultMap 에서 확인 |
| `OUTPUT 선언 → 변수명` | 최종 출력으로 쓸 변수를 정한 라인 |

### 6.5 계산식 값 확인

VAL 이 `[$ … $]` 계산식이면, OUTPUT 칸에 **실제로 대입된 값을 채운 식**이 회색으로 함께 표시됩니다.

```
VAL  : [$ {EL_EHP}-{BOT_GAP}+{EL_EHTRH}+{EL_EHO}-{TOP_GAP} $]
표시 : RAIL_TH = 100745  ([$ 2200-175+93000+5820-100 $])
```

- 변수값은 **① 그 라인 실행 직전의 resultMap → ② 호기 영업사양** 순서로 찾습니다.
- 끝내 못 찾은 변수는 `{EL_EHP}` 처럼 **원래 모양 그대로** 남습니다.

## 7. 툴바 기능

| 기능 | 사용법 | 이럴 때 씁니다 |
|---|---|---|
| **필터** | 전체 / TRUE / FALSE / 실행된 라인 / 미실행 중 선택. 버튼 옆 숫자 = 건수 | TRUE 만 보며 실제 실행 경로 따라가기 |
| **최종 OUTPUT (N)** | 마지막으로 실행된 라인 기준 resultMap 전체를 상세 패널에 표시 | PID 가 최종적으로 만든 값 확인 |
| **CSV 저장** | 지금 보이는 라인을 CSV 파일로 저장 (→ [9장](#9-csv-저장)) | 결과를 엑셀로 공유 |
| **원본 컬럼 펼치기** | SPEC1/CON1, KEY1/VAL1 … 처럼 기존 JSP 화면과 같은 컬럼 배치 | 기존 화면과 나란히 비교 |
| **빈 라인 숨기기** | 내용도 ADDR 도 없는 라인 숨김 | 표를 짧게 보기 |
| **검색** | SPEC · CON · KEY · VAL · ADDR · REMARK · 라인번호에서 검색 (대소문자 무시) | `EL_ATYP` 가 쓰인 라인만 보기 |
| **확대/축소** `[− 100% +]` | 결과 테이블만 50% ~ 200% 로 조절. `100%` 클릭 = 원래 크기 | 라인이 많을 때 축소해서 한눈에 보기 |

- **필터 · 검색 · 빈 라인 숨기기는 함께 적용**됩니다. 예) FALSE + `EL_ATYP` → EL_ATYP 가 들어간 FALSE 라인만
- 툴바의 `N / M 라인` = 지금 보이는 라인 수 / 전체 라인 수
- 확대/축소 배율은 **브라우저에 저장**되어 다음에 열어도 유지됩니다.

## 8. 라인 상세 패널

결과 표에서 라인을 **클릭**하거나 `Enter` 를 누르면 오른쪽에 열립니다.

| 순서 | 항목 | 내용 |
|---|---|---|
| 1 | 요약 | TRUE / FALSE / 미실행 배지, 라인 번호, ADDR, GOTO, DOUID, REMARK |
| 2 | **조건** | SPEC (한글 사양명), 조건값, 일치/불일치, **(현재값: 호기 실제값)** |
| 3 | 결과 (KEY = VAL) | 라인이 만드는 변수와 값. 계산식이면 아래에 `= 값이 채워진 식` |
| 4 | 이 라인 실행 후 resultMap | 이 라인까지 쌓인 전체 변수와 값. 이 라인의 KEY 는 **노란색** 강조 |

**예시 — 조건 영역**

| SPEC | 조건 |
|---|---|
| EL_ACD2 | KS230302 (불일치)<br>(현재값: **KS190328**) |

→ 조건은 `KS230302` 인데 이 호기는 `KS190328` 이라 불일치했다는 것을 바로 알 수 있습니다.

**사용 팁**

- 패널이 열린 채로 `↑` `↓` 또는 패널의 `▲` `▼` 버튼으로 라인을 옮기면 내용도 따라 바뀝니다.
- resultMap 위 검색창에 변수명이나 값을 넣으면 해당 항목만 남습니다. 라인을 옮겨도 검색어는 유지됩니다.
- resultMap 은 **값이 바뀐 라인에만** 나옵니다. 없으면 바로 위 라인들을 보세요.
- 패널과 표 사이 경계선을 끌어 **폭 조절**이 가능하며, 폭은 브라우저에 저장됩니다.
- **닫기 ✕** 또는 `Esc` 로 닫습니다.

## 9. CSV 저장

툴바의 **CSV 저장** 버튼을 누르면 **지금 화면에 보이는 라인만** 저장됩니다 (필터 · 검색 · 빈 라인 숨기기 적용 상태 그대로).

| 항목 | 내용 |
|---|---|
| 파일명 | `PID_<호기>_<PID>.csv` (예: `PID_208223L01_EL_PB186A01.csv`) |
| 인코딩 | UTF-8 (BOM 포함) — **엑셀에서 더블클릭으로 바로 열어도 한글이 깨지지 않음** |
| 저장 대상 | 현재 보이는 라인 (보이는 라인이 없으면 안내 후 저장 안 함) |

**컬럼 구성**

| 컬럼 | 내용 |
|---|---|
| `#` · `ADDR` · `결과` | 라인 번호, 주소, TRUE / FALSE / 미실행 |
| `조건 (SPEC = CON)` | 조건 목록. 불일치 조건 뒤에 `(불일치)` |
| `호기값` | 조건 SPEC 의 호기 실제값 (`SPEC = 값`) |
| `결과 (KEY = VAL)` | 결과 정의 |
| `GOTO` · `OUTPUT` · `REMARK` | 이동 대상, 실제 만들어진 값, 설명 |

한 칸에 여러 항목이 있으면 **줄바꿈으로 구분**됩니다 (엑셀에서 셀 안 줄바꿈으로 보임).

> **활용 예** — FALSE 필터를 켜고 CSV 저장 → "어떤 조건이 어떤 호기값 때문에 막혔는지" 목록이 바로 만들어집니다.

## 10. 특성코드 사전

상단의 **특성코드 사전** 버튼을 누르면 새 창이 열립니다. SPEC 코드의 **한글명**과 **선택 가능한 값 목록**을 확인할 수 있습니다.

| 영역 | 내용 |
|---|---|
| 이 PID에서 사용한 특성 | 현재 결과의 SPEC 을 처음 나온 순서대로 표시. 코드 · 한글명 · 값 개수 · 사용 라인 수 + 이 PID 조건에 쓰인 값(칩) |
| 그 외 특성코드 | 나머지 특성코드는 **검색했을 때만** 표시 (최대 50종) |

- 특성 줄을 클릭하면 값 목록이 펼쳐집니다. 15개 이하면 처음부터 펼쳐져 있습니다. **모두 펼치기 / 모두 접기** 사용 가능
- 값 목록에서 **이 PID 조건에 쓰인 값**은 강조 표시됩니다.
- 검색창에 코드 · 한글명 · 값 · 설명 아무거나 입력 (`/` 로 이동, `Esc` 로 지우기)
- 시뮬레이터에서 다른 PID 를 실행하면 사전도 자동 갱신됩니다. 안 바뀌었으면 **PID 결과 다시 읽기** 클릭
- "특성코드 마스터에 없음" 으로 나오는 SPEC 은 `BABBIT_YN` 처럼 **PID 안에서 만든 변수**일 가능성이 큽니다.

> 창이 안 열리고 *"팝업이 차단되었습니다"* 가 뜨면 → 주소창 오른쪽 **팝업 차단 아이콘**에서 이 사이트 팝업을 허용하세요.

## 11. 단축키 · 마우스 조작

실행 직후 결과 표에 포커스가 있고 첫 라인이 선택되어 있어, 바로 키보드로 이동할 수 있습니다.

| 조작 | 동작 | 위치 |
|---|---|---|
| `Enter` | 조회 조건에서: 실행 / 결과 표에서: 라인 상세 열기 | 조회 조건, 결과 표 |
| `↑` `↓` | 이전 / 다음 라인 | 결과 표 |
| `PageUp` `PageDown` | 한 화면씩 이동 | 결과 표 |
| `Home` `End` | 첫 / 마지막 라인 | 결과 표 |
| `←` `→` | 좌우 스크롤 | 결과 표 |
| `+` `-` `0` | 확대 / 축소 / 원래 크기 | 결과 표 |
| `Ctrl` + 마우스 휠 | 테이블만 확대/축소 (브라우저 전체 확대 아님) | 결과 표 위 |
| `/` | 툴바 검색창으로 이동 | 어디서든 (입력 중 제외) |
| `Esc` | 상세 패널 닫기 | 어디서든 |
| 라인 클릭 | 선택 + 상세 패널 열기 | 결과 표 |
| GOTO 값 클릭 | 해당 ADDR 라인으로 이동 (노란색 깜빡임) | 결과 표 |
| 드래그 | 표를 잡고 상하좌우 이동 | 결과 표 |

- GOTO 대상 라인이 필터나 검색으로 숨겨져 있으면 **필터를 자동으로 풀고** 이동합니다.
- 검색창에서 `Enter` 나 `↓` 를 누르면 결과 표의 첫 라인으로 바로 이동합니다.

## 12. 결과 공유하기 (URL)

실행하면 주소창 URL 에 조회 조건이 자동으로 붙습니다. **URL 을 복사해 보내면 받은 사람도 같은 조건으로 바로 실행**됩니다.

```
/pid/pidSimulView?hogi=208223L01&PID=EL_PB186A01&testVersion=&isfloor=&floor=&type=
```

| 규칙 | 내용 |
|---|---|
| 새로고침 (F5) | 같은 조건으로 다시 실행 |
| `PID` | **대문자**로 적어야 함 (`pid=` 는 인식 안 됨) |
| testVersion 켜기 | `testVersion=on` |
| isfloor · floor · type 값이 있으면 | 화면이 열릴 때 추가 조건 영역이 펼쳐진 채로 보임 |

## 13. 자주 묻는 질문 · 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 결과가 뜨기까지 15초 이상 걸림 | PID 결과와 영업사양을 **둘 다 받은 뒤** 화면을 그림. 영업사양 조회가 오래 걸림 | 기다리면 됩니다. 같은 호기로 재실행하면 빨라짐 |
| *"결과가 없습니다"* | 호기 · PID 오타, 또는 PLM 이 빈 결과를 돌려줌 | 철자 확인. 그래도 같으면 서버 담당자에게 PLM 응답 확인 요청 |
| *"API 호출 실패: HTTP …"* | 서버가 PLM 에 접속 못 했거나 서버 오류 | 사내망 연결 확인 후 재실행. 반복되면 화면 캡처해 서버 담당자에게 전달 |
| 오른쪽 위에 **빨간 글씨** (영업사양 로딩 실패/0건) | 호기 영업사양을 못 불러옴 | 재실행. 계속되면 호기 번호 확인, 서버 담당자 문의 |
| 계산식에 `{EL_EHP}` 처럼 변수가 그대로 남음 | 그 변수가 resultMap 에도 영업사양에도 없음 | 오른쪽 위 영업사양 상태 확인. 정상이면 `MAX_OH` 처럼 **PID 안에서만 쓰는 변수**일 수 있음 |
| 조건에 **현재값**이 안 보임 | 그 SPEC 이 resultMap · 영업사양 어디에도 없음 | 정상일 수 있음 (PID 내부 변수 등). 영업사양 상태도 확인 |
| 조건에 한글 사양명이 안 보임 | 사양명 목록 로딩 실패 (코드는 그대로 보임) | 페이지 새로고침 |
| 특성코드 사전 창이 안 열림 | 브라우저 팝업 차단 | 주소창 팝업 차단 아이콘에서 허용 |
| 라인이 왜 FALSE 인지 모르겠음 | 조건 하나 이상 불일치 | **빨간 칩**에 마우스 → 호기값 비교. 상세 패널의 현재값 확인 |
| 라인이 회색(미실행) | 앞 라인의 GOTO 가 건너뜀 | 정상. 실행 경로만 보려면 **실행된 라인** 필터 |
| CSV 를 열었더니 한글이 깨짐 | 다른 프로그램에서 인코딩을 다르게 읽음 | 엑셀에서 더블클릭으로 열기 (UTF-8 BOM 포함) |
| 표 글씨가 너무 작음/큼 | 확대/축소 배율이 저장되어 있음 | 툴바의 `100%` 클릭 또는 결과 표에서 `0` |
