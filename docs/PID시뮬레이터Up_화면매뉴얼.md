# PID 실행 시뮬레이터 (PLM DB 직접 실행) — 화면 사용 매뉴얼

| 항목 | 내용 |
|---|---|
| 화면명 | PID 실행 시뮬레이터 |
| 접속 경로 | 사이드바 > PID 실행 시뮬레이터 (`/simulateup/pidSimulatorUp`) |
| 대상 데이터 | PLM DB 의 PID 로직 · 공사 영업사양 |
| 저장 여부 | PID 로직과 영업사양을 변경하지 않습니다 (조회 전용) |
| 문서 버전 | 1.0 (2026-11-06) |
| 작성 | 수배로직설계팀 |

> 이전 화면(`/pid/pidSimulView`)의 사용법은 `PID시뮬레이터_화면매뉴얼.md` 를 참고하세요.

---

## 1. 개요

공사번호와 PID 를 입력하면 PLM DB 의 로직과 영업사양으로 PID 를 **라인 단위로 실행**해 결과를 보여주는 화면입니다.

- **원인 분석** : 라인별 TRUE / FALSE / 미실행, 조건별 일치 여부, 계산식 대입값, 최종 OUTPUT 확인
- **버전 지정 실행** : 대상 PID 와 CALL 하위 PID 의 버전을 각각 골라 실행
- **기준일 실행** : 날짜를 고르면 그 시점의 PID 로직 버전을 찾아 실행 ([4장](#4-기준일로-과거-시점-로직-실행))
- **하위 로직 분석** : CALL 로 호출된 하위 PID 의 호출 관계와 영업사양 사용 내역 확인
- **자재수배 확인** : 블럭번호 PID 를 PICK 별로 실행하고 수량 계산

> **기준일은 PID 로직 버전에만 적용됩니다.** 영업사양은 항상 실행 시점의 현재 값을 사용합니다.
> 해당 날짜 이후 영업사양이 바뀌었다면 당시 수배 결과와 다를 수 있습니다.

## 2. 화면 구성

```
┌──────────────────────────────────────────────────────────────────────┐
│ 헤더 : 공사번호 · PID · 버전 · 기준일 · 추가 조건 · 실행 · 분석 도구 버튼  │
│ 하위 PID 버전 : 호출된 하위 PID 의 버전 선택 (실행 후 표시, 접기 가능)      │
│ 자재수배 PICK : PICK 선택 (블럭번호 PID 일 때 표시)                       │
├──────────────────────────────────────────────────────────────────────┤
│ 툴바 : 필터 · 최종 OUTPUT · 최신과 비교 · 최종 영업사양 · 검색 · 확대       │
├───────────────────────────────────────────────┬──────────────────────┤
│ 결과 테이블 (이 영역만 스크롤)                   │ 상세 패널 (라인 클릭)   │
└───────────────────────────────────────────────┴──────────────────────┘
```

## 3. 조회

### 3.1 입력 항목

| 항목 | 필수 | 설명 |
|---|---|---|
| 공사번호 | 필수 | 공사번호(예: `206663L01`) 또는 공사정보 ouid(예: `elv_info$vf@a810066d`). 영문은 대문자로 자동 변환됩니다 (ouid 제외) |
| PID | 필수 | 예: `D375A`. 입력을 멈추면 버전 목록을 자동으로 불러옵니다 |
| 버전 | 선택 | `최신`(기본) · `TEST` · `vN`. 등록일시 · 비고 · 작성자가 함께 표시됩니다 |
| 기준일 | 선택 | 달력에서 날짜 선택 ([4장](#4-기준일로-과거-시점-로직-실행)) |
| 추가 조건 > 층 (FLOOR_NAME) | 선택 | **층별 PID 일 때만** 입력 가능 |
| 추가 조건 > 전처리 PID | 선택 | 대상 PID 보다 먼저 실행해 결과를 영업사양에 반영. 쉼표로 여러 개 입력 (예: `EL_P001, EL_P002`) |

입력 후 <kbd>Enter</kbd> 또는 **실행** 을 누릅니다. PID 를 바꾸면 하위 PID 버전 선택이 초기화되고 버전이 `최신` 으로 돌아갑니다.

### 3.2 실행 후 상단 표시

```
206663L01 / D375A PID명 [최신 v12] [층별 PID · 1F] · 1.8초 · 경고 1건
```

| 표시 | 의미 |
|---|---|
| `최신 v12` / `v10 · 최신 v12` / `TEST` | 실제 실행한 대상 PID 버전 |
| `층별 PID` | 층별 PID 이며, 층을 입력했으면 층 이름 표시 |
| `JAVA` | JAVA 방식 PID. 라인 없이 결과값만 표시 |
| 주황색 알림 띠 | 층 정보 로드 실패, 하위 PID 실행 실패 등. `✕` 로 닫을 수 있습니다 |

### 3.3 주소로 바로 실행 · 공유

실행하면 조건이 주소창에 반영되어, 주소를 공유하면 같은 조건으로 바로 실행됩니다. 하위 PID 버전 지정도 포함됩니다.

```
/simulateup/pidSimulatorUp?project=206663L01&pid=D375A&version=10&subVersions=EL_P001:3,EL_P002:-1
```

> 주소에는 고른 **버전**이 저장되며, 기준일 날짜와 PICK 은 저장되지 않습니다.

## 4. 기준일로 과거 시점 로직 실행

달력에서 날짜를 고르면 **그 날짜 이전(당일 포함) 중 가장 최근에 등록된 버전**을 PID 마다 선택합니다. TEST 버전은 제외합니다.

### 4.1 사용 순서

하위 PID 목록은 실행 결과로 만들어지므로, 아래 순서대로 진행해야 하위 PID 까지 기준일 버전이 적용됩니다.

1. 공사번호와 PID 를 입력하고 **기준일** 선택 → 대상 PID 버전이 자동으로 선택됩니다
2. **실행** → 그 버전이 호출하는 하위 PID 목록이 나타납니다. 이때 하위 PID 는 아직 최신 버전입니다
3. 기준일을 **지웠다가 다시 선택** → 하위 PID 버전이 선택되고 `변경 N개 (적용 실행 필요)` 가 표시됩니다
4. **하위 버전 적용 실행**
5. 하위 PID 가 새로 나타날 수 있으므로, 3~4 를 반복해 `변경` 이 더 나오지 않으면 완료입니다

### 4.2 주의사항

| 상황 | 동작 |
|---|---|
| 하위 PID 에 기준일 이전 버전이 없음 | 그 PID 는 **최신 버전**으로 실행됩니다. 안내 문구의 `해당 버전 없음 N개 → 최신` 을 확인하세요 |
| 대상 PID 에 기준일 이전 버전이 없음 | 경고 창이 뜨고 대상 PID 버전은 바뀌지 않습니다 |
| 전처리 PID 와 그 하위 PID | 기준일과 관계없이 **항상 최신 버전**으로 실행됩니다 |
| 버전을 직접 변경 | 기준일 칸이 비워집니다 |
| PID 를 변경 | 버전은 `최신` 으로 돌아가지만 기준일 칸의 날짜는 남습니다. 기준일을 다시 선택하세요 |
| 영업사양 | 기준일과 관계없이 **현재 값**을 사용합니다 |

### 4.3 기준일 이전 / 기준일 이후 버튼

하위 PID 버전 줄의 버튼은 **달력 날짜가 아니라 입력한 대상 PID 버전의 등록일**을 기준으로 가장 가까운 하위 버전을 고릅니다. 고른 뒤 **하위 버전 적용 실행** 을 눌러야 반영됩니다.

### 4.4 화면별 기준일 적용 범위

전체 PID 에 같은 기준일을 한 번에 적용하려면 **수량 계산** 팝업의 기준일을 사용하세요 ([9장](#9-수량-계산)). 단, 수량 계산은 라인별 결과를 보여주지 않습니다.

| 구분 | 메인 화면 기준일 | 수량 계산 팝업 기준일 |
|---|---|---|
| 대상 PID | 적용 | 적용 |
| 하위 PID | 직전 실행에서 호출된 PID 만 선택, 적용 실행 필요 | 호출되는 모든 PID 에 자동 적용 |
| 전처리 PID | 최신 | 적용 |
| 자재수배 PID (EL_P / SH_P) | 최신 (PICK 실행 시) | 적용 |
| 이전 버전이 없는 하위 PID | 최신으로 실행 | 실행하지 못하고 경고 표시 |
| 영업사양 | 현재 값 | 현재 값 |

## 5. 하위 PID 버전

실행하면 대상 PID 가 CALL 로 실행한 하위 PID 가 헤더 아래에 표시됩니다. 전처리 PID 는 제외되며, 실행되지 않은 CALL 은 목록에 나오지 않습니다 (호출 관계도에서 확인).

| 기능 | 설명 |
|---|---|
| 하위 버전 적용 실행 | 고른 버전으로 다시 실행. 지정하지 않은 하위 PID 는 최신 버전 |
| 모두 최신 | 모든 하위 PID 를 최신으로 되돌려 다시 실행 |
| 기준일 이전 / 이후 | [4.3](#43-기준일-이전--기준일-이후-버튼) 참고 |
| 검색 | 하위 PID · 이름 검색 |
| 필터 | `전체` · `지정` · `변경` · `실패` · `TEST 있음` |
| 표로 보기 / 칩으로 보기 | 표 보기 설정은 브라우저에 기억됩니다 |

표 보기에서는 `PID` · `이름` · `깊이` · `호출` · `실행` · `최신` 열을 눌러 정렬할 수 있습니다 (세 번째 클릭은 호출 순서로 복귀). `버전 바로 선택` 열에서 최신, TEST, 최신 직전 3개 버전을 바로 고를 수 있습니다.

| 표시 | 의미 |
|---|---|
| 깊이 | 대상 PID 가 1, 바로 아래 CALL 이 2. 칩 보기의 `↳` 는 하위의 하위 |
| 보라색 | 버전을 지정해 실행한 하위 PID |
| 노란색 | 골랐지만 아직 실행하지 않은 변경 |
| 빨간색 | 실행 실패 |

- 버전 지정은 PID 이름 기준입니다. 같은 PID 는 어느 위치에서 호출되어도 같은 버전으로 실행됩니다.
- 전처리 PID 내부의 CALL 에는 버전 지정이 적용되지 않습니다.

## 6. 결과 테이블

### 6.1 컬럼

| 컬럼 | 설명 |
|---|---|
| `#` / `ADDR` | 라인 번호 / 주소 (왼쪽 고정) |
| 결과 | `TRUE` · `FALSE` · `-`(미실행) |
| 조건 (SPEC = CON) | 조건과 일치 여부. 마우스를 올리면 영업사양 값 표시 |
| 결과 (KEY = VAL) | 조건이 맞을 때 설정되는 값 |
| GOTO | `→ ADDR` 클릭 시 그 라인으로 이동. 필터에 가려져 있으면 필터가 해제됩니다 |
| OUTPUT | TRUE 라인에서 계산된 값 |
| REMARK | 비고 |

### 6.2 색 구분

| 표시 | 의미 |
|---|---|
| 초록 행 | TRUE — 조건 만족 |
| 빨강 행 | FALSE — 조건 불만족 |
| 회색 행 | 미실행 — GOTO / STOP 으로 건너뜀 |
| 진한 초록 칸 + `✓` | 조건 일치 |
| 진한 빨강 칸 + `✗` | 조건 불일치 |

### 6.3 OUTPUT 읽는 법

| 표시 | 의미 |
|---|---|
| `KEY = 값` | 이 라인에서 저장된 값 |
| `KEY = 값 (계산식)` | 계산식에 실제 값을 대입한 식을 괄호로 표시 |
| `CALL(PID) → resultMap N건 보기` | 하위 PID 호출 라인. 클릭하면 라인 상세의 resultMap 으로 이동 |
| PID 옆 `v3` 배지 | 버전을 지정해 실행한 하위 PID |
| PID 옆 `실패` 배지 | 하위 PID 실행 실패. 마우스를 올리면 사유 표시 |

### 6.4 CALL PID 새 탭 실행

KEY 가 CALL 인 라인의 PID 를 클릭하면 같은 공사번호로 그 PID 를 **새 탭에서 단독 실행**합니다. 버전을 지정해 실행한 PID 는 그 버전으로 열립니다.

> 새 탭에는 층, 전처리 PID, 하위의 하위 버전 지정, 상위 PID 에서 넘어온 값이 전달되지 않습니다.
> 따라서 상위 PID 안에서 호출된 결과와 값이 다를 수 있습니다.

## 7. 툴바

| 기능 | 설명 |
|---|---|
| 필터 | `전체` · `TRUE` · `FALSE` · `실행된 라인` · `미실행`. 버튼마다 건수 표시 |
| 최종 OUTPUT (N) | PID 실행 최종 결과값. 키 / 값 검색 가능 |
| 최신과 비교 | 버전을 지정해 실행했을 때 활성화 ([8.5](#85-최신과-비교)) |
| 최종 영업사양 (N) | 전처리 PID · CALL 결과가 반영된 영업사양. 코드 / 사양명 / 값 검색 가능 |
| 원본 컬럼 펼치기 | `SPEC1/CON1 …`, `KEY1/VAL1 …` 을 각각 컬럼으로 표시 |
| 빈 라인 숨기기 | 내용과 ADDR 이 없는 라인 숨김 |
| 검색 | ADDR · GOTO · REMARK · 라인 번호 · OUTPUT · SPEC · CON · KEY · VAL 대상 |
| 확대 / 축소 | 결과 테이블만 50% ~ 200%. 배율 클릭 시 100% (브라우저에 기억) |
| 범례 / 단축키 | 색 의미와 단축키 안내 |

### 7.1 상세 패널

라인을 클릭하면 오른쪽에 열립니다. 왼쪽 경계를 끌어 폭을 조절할 수 있으며, 폭은 브라우저에 기억됩니다.

| 구역 | 내용 |
|---|---|
| 머리 | 결과 · LINE · ADDR · GOTO · REMARK |
| 조건 | SPEC(사양명) · CON · 일치 여부 · 영업사양값 |
| 결과 (KEY = VAL) | VAL 원문 |
| OUTPUT | 계산된 값과 대입된 식 |
| 이 라인 실행 후 resultMap | **CALL 라인만** 표시. 이 라인의 KEY 는 강조, 키 / 값 검색 가능 |

> 화면의 **영업사양값은 PID 실행이 끝난 뒤의 최종 값**입니다. 실행 중 PID 가 값을 바꿨다면 라인을 비교하던 시점의 값과 다를 수 있습니다.

## 8. 분석 도구

헤더 버튼을 누르면 새 창으로 열립니다. 메인 화면의 실행 결과를 읽어 표시하며, 다시 실행하면 열려 있는 창도 함께 갱신됩니다. 창이 열리지 않으면 브라우저에서 이 사이트의 팝업을 허용하세요.

### 8.1 특성코드 사전

현재 결과에 쓰인 특성코드의 한글명, 값 목록, 사용 라인 수를 확인하고 전체 특성코드를 검색합니다.

### 8.2 호출 관계도 (Mind-Map)

CALL 로 이어진 하위 PID 를 트리로 표시합니다.

| 표시 | 의미 |
|---|---|
| 상자 색 | 대상 PID · 실행됨 · 실행 실패 · 미실행 |
| 회색 점선 | 로직에 CALL 은 있지만 이번 실행에서 호출되지 않음 |
| 선 위 `×N` | N번 호출 |
| 오른쪽 위 배지 | 실행 버전, 버전 지정 실행 등 (화면의 `범례` 참고) |

| 기능 | 설명 |
|---|---|
| 찾기 | PID / 이름 검색. <kbd>Enter</kbd> 로 다음 결과, <kbd>/</kbd> 로 입력 |
| 가로 / 세로, 기본 / 작게 | 그리는 방향과 상자 크기 |
| 모두 펼치기 / 접기, 묶어 보기 | 하위가 없는 형제 PID 6개 이상은 격자로 묶음 |
| 미실행 표시 | 호출되지 않은 CALL 표시 여부 |
| 이 가지만 보기 | 선택한 PID 아래만 표시 (<kbd>F</kbd>, 해제 <kbd>Esc</kbd>) |
| 상자 클릭 | 호출한 PID · 호출된 PID 표시, `이 PID 실행 (새 탭)` |
| 이미지 저장 | 펼쳐진 관계도를 PNG 로 저장 |

같은 PID 를 여러 곳에서 호출하면 하위는 처음 나온 위치에만 펼쳐집니다.

### 8.3 영업사양 영향도

PID 와 영업사양의 사용 관계를 표로 봅니다. 사양 역할은 `조건 비교` · `값 계산` · `값 생성` · `이번엔 안 씀` 으로 표시합니다.

| 탭 | 확인 내용 |
|---|---|
| PID 기준 | PID 가 직접 쓰는 사양, CALL 하위에서 쓰는 사양, 하위와 주고받는 값 |
| 영업사양 기준 | 그 사양을 쓰는 PID 와 호출 경로 |
| 점검할 점 | 값 출처가 없는 사양, PID 가 덮어쓰는 영업사양, 여러 PID 가 만드는 값, PID 사이 전달값, 영향 범위가 넓은 사양, 로직에만 있는 사양 |
| 전체 표 | PID × 사양 교차표 |

`이번 실행에서 쓴 것만` 으로 사용한 사양만 볼 수 있고, `CSV 저장` 으로 내역을 저장합니다.

> 전처리 PID 는 포함되지 않으며, 실행되지 않은 CALL 대상 PID 는 로직을 읽지 않아 빠집니다.
> JAVA 방식 PID 는 사용 사양을 기록하지 못합니다.

### 8.4 영업사양 흐름도

| 모드 | 확인 내용 |
|---|---|
| 상→하 | PID 에서 시작해 CALL 하위 PID 와 각자 쓰는 사양으로 내려갑니다 |
| 하→상 | 사양에서 시작해 쓰는 PID 와 그 상위 PID 로 올라갑니다 (영향 범위) |

왼쪽 목록에서 시작점을 고릅니다. `값 전달 선` 은 한 PID 가 만든 값을 다른 PID 가 읽는 관계를 점선으로 표시합니다.

> 영향도와 흐름도는 **PICK 없이 실행한 결과**로 확인하세요. PICK 실행에서는 영업사양 사용 내역을 기록하지 않습니다.

### 8.5 최신과 비교

버전을 지정한 실행(A)과, 같은 공사번호 · 층 · 전처리 PID 로 **모든 PID 를 최신 버전으로 다시 실행한 결과**(B)의 최종 OUTPUT 을 키별로 비교합니다. 기준일로 실행한 뒤 사용하면 그 시점 로직과 현재 로직의 차이를 볼 수 있습니다.

| 기능 | 설명 |
|---|---|
| 필터 | `차이 전체` · `값 다름` · `A 에만` · `B 에만` · `같음` · `전체` |
| OUTPUTxxxx 키 숨기기 | 내부 참조용 키 숨김 (기본 켜짐) |
| 다시 비교 / CSV 저장 | 재실행 / 보이는 행을 CSV 로 저장 |

> B 는 PICK 없이 실행됩니다. **PICK 실행 결과를 비교하면 PICK 때문에 생긴 차이도 함께 표시**되므로, 버전 차이만 보려면 PICK 없이 실행한 뒤 비교하세요.

## 9. 수량 계산

**수량 계산** 버튼을 누르면 블럭번호 PID 의 PICK 별 결과를 표로 보여주는 팝업이 열립니다.

| 구분 | 블럭번호 PID 예 | 자재수배 PID |
|---|---|---|
| 엘리베이터 | `B181B` | `EL_PB181B` |
| 선박 (`SH` 로 시작) | `SH_B181B` | `SH_PB181B` |

계산 순서 : 전처리 PID 실행 → 자재수배 PID 실행 후 결과를 영업사양에 반영 → 결과변수(`EL_PB181B`, `EL_PB181B_1` …)마다 `PICK` 을 넣어 블럭번호 PID 실행

| 항목 | 설명 |
|---|---|
| 표 | 열 = PICK(PICK 값 표시), 행 = 결과 KEY. `QTY` 가 첫 행입니다 |
| 값이 다른 행만 | 기본 켜짐. QTY 행과 오류 행은 항상 표시됩니다 |
| 검색 | KEY / 값 검색 |
| 기준일 + 다시 계산 | 모든 PID 를 기준일 이전 가장 가까운 버전으로 계산. 비우면 최신 |
| 기준일 실행 버전 | 기준일 계산 시 PID 별 실행 버전과 등록일시 |

- 메인 화면의 공사번호, PID, 버전, 층, 전처리 PID 가 전달됩니다.
- **메인 화면의 기준일과 하위 PID 버전 지정은 전달되지 않습니다.** 기준일은 팝업에서 다시 선택하세요.
- 팝업에서 기준일을 고르면 전달받은 버전은 무시됩니다.
- PICK 값(자재번호)이 없는 열은 공백으로 표시됩니다.

## 10. 자재수배 PICK

자재수배 PID 가 있는 블럭번호 PID 를 실행하면 **자재수배 PICK** 줄이 나타납니다. PICK 을 고르면 `PICK = 고른 키` 를 넣어 라인 단위로 바로 다시 실행합니다.

- `(빈 값)` 은 자재번호가 없는 결과변수입니다.
- **PICK 해제** 또는 **실행** 을 누르면 PICK 없이 다시 실행합니다.
- **하위 버전 적용 실행** 과 **모두 최신** 도 PICK 없이 실행합니다. 버전을 바꾼 뒤 PICK 을 다시 고르세요.
- PICK 목록과 PICK 실행에 쓰는 **자재수배 PID 는 항상 최신 버전**입니다. 대상 PID 버전과 하위 PID 버전 지정만 적용됩니다.
- 자재수배 PID(`EL_P` / `SH_P`) 를 직접 실행할 때는 표시되지 않습니다.

## 12. 활용 예시

**결과가 예상과 다른 원인 라인 찾기**
실행 → `최종 OUTPUT` 에서 이상한 KEY 확인 → 검색창에 KEY 입력 → TRUE 라인의 OUTPUT 과 조건 확인

**특정 날짜의 로직으로 결과 재현**
[4.1](#41-사용-순서) 순서로 실행 → `최신과 비교` 로 현재 로직과의 차이 확인

**특정 날짜 기준 블럭 수량 확인**
블럭번호 PID 입력 → `수량 계산` → 팝업에서 기준일 선택 → `다시 계산` → `기준일 실행 버전` 확인

**하위 PID 버전 변경의 영향 확인**
실행 → 하위 PID 버전 선택 → `하위 버전 적용 실행` → `최신과 비교`

**하위 로직까지 호출 구조 파악**
실행 → `호출 관계도` → 실패 PID · 미실행 CALL 확인 → 상자 클릭 후 `이 PID 실행 (새 탭)`

**영업사양 변경의 영향 범위 확인**
실행 → `영업사양 흐름도` → `하→상` 에서 사양 선택. 목록으로 보려면 `영업사양 영향도` 의 `영업사양 기준` 탭 사용

## 13. 주의사항 · FAQ

| 상황 | 설명 |
|---|---|
| 기준일을 고르면 당시 수배 결과와 항상 같나요? | **아니요.** PID 로직 버전만 과거 기준이고 영업사양은 현재 값입니다. 전처리 PID, PICK 실행의 자재수배 PID, 이전 버전이 없는 하위 PID 는 메인 화면에서 최신으로 실행됩니다 |
| 기준일을 골랐는데 하위 PID 가 최신이에요 | 하위 PID 목록은 실행 후 만들어집니다. [4.1](#41-사용-순서) 순서로 진행하세요 |
| 하위 PID 버전을 골랐는데 결과가 그대로예요 | **하위 버전 적용 실행** 을 눌러야 반영됩니다. 노란색은 아직 실행하지 않은 변경입니다 |
| `최신과 비교` 가 비활성이에요 | 버전을 지정하지 않은 전체 최신 실행입니다 |
| `층` 입력칸이 비활성이에요 | 층별 PID 가 아닙니다. 층별 여부는 최신 버전 기준입니다 |
| `층 정보를 찾을 수 없습니다` | 입력한 층 이름이 공사의 FLOOR_NAME 과 일치하는지 확인하세요 |
| JAVA 표시가 있고 라인이 없어요 | JAVA 방식 PID 는 라인 정보 없이 결과값만 표시됩니다 |
| 하위 PID 에 빨간 표시가 있어요 | 실행에 실패한 하위 PID 입니다. 알림 띠나 마우스 오버로 사유를 확인하세요 |
| `버전 없음 (PID 확인)` | 입력한 PID 의 버전이 없습니다. PID 를 확인하세요 |
| 팝업에 `실행 결과가 없습니다` 가 나와요 | 메인 화면에서 실행한 뒤 `다시 읽기` 를 누르세요. 메인 화면을 닫았다면 다시 열어야 합니다 |
| 분석 창이 열리지 않아요 | 브라우저에서 이 사이트의 팝업을 허용하세요 |
