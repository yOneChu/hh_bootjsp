# PID 실행 시뮬레이터 안내 메일 (발송용 초안)

> 아래 제목·본문을 그대로 메일에 붙여넣어 사용합니다.
> 첨부 : `PID시뮬레이터_화면매뉴얼.md` (또는 PDF 변환본)

---

## 1. 메일 제목

**권장안**

```
[안내] PID 실행 시뮬레이터 화면 오픈 및 사용 매뉴얼 배포
```

**대안**

```
[수배로직설계팀] 호기별 PID 실행 결과 확인 화면 안내 (매뉴얼 첨부)
[안내] PID 결과가 왜 이렇게 나왔는지, 라인별로 확인하는 화면 오픈
```

---

## 2. 메일 본문

```
안녕하세요, 수배로직설계팀입니다.

호기와 PID 를 입력하면 그 호기 사양으로 PID 를 한 줄씩 실행한 결과를 보여주는
'PID 실행 시뮬레이터' 화면을 안내드립니다.
PID 결과가 예상과 다를 때 어느 라인에서 무엇 때문에 그렇게 되었는지 바로 확인하실 수 있습니다.
사용 방법은 첨부 매뉴얼을 참고해 주시기 바랍니다.


■ 접속 경로

  /pid/pidSimulView  (사내망)


■ 주요 기능

  1. 라인별 실행 결과
     - 각 라인이 TRUE(실행) / FALSE(조건 불일치) / 미실행 중 무엇이었는지 색으로 구분합니다.
     - 조건(SPEC = CON)마다 일치·불일치를 표시하고, 마우스를 올리면 호기 실제값을 보여줍니다.
     - TRUE 라인은 실제로 계산된 값(OUTPUT)을 보여주며,
       계산식이면 변수에 대입된 값을 채운 식까지 함께 표시합니다.

  2. 라인 상세
     - 라인을 클릭하면 조건값과 호기 원래값을 나란히 비교하고,
       그 라인 실행 직후의 전체 변수(resultMap)를 검색할 수 있습니다.
     - 최종 OUTPUT 버튼으로 마지막 결과 변수 목록을 바로 확인합니다.

  3. 찾기 · 반출
     - TRUE / FALSE / 미실행 필터, 키워드 검색, GOTO 클릭 이동을 지원합니다.
     - 보이는 라인을 CSV 로 저장할 수 있습니다. (호기값 컬럼 포함)

  4. 특성코드 사전
     - 이 PID 에서 사용한 특성코드의 한글명과 값 목록을 새 창으로 확인합니다.

  5. 결과 공유
     - 실행하면 주소창에 조건이 반영됩니다. 주소를 그대로 전달하면 같은 결과가 열립니다.


■ 사용 시 참고사항

  - PID 실행 결과는 PLM 에서 가져옵니다. PLM 접속이 안 되면 결과가 표시되지 않습니다.
  - 호기 영업사양을 읽지 못하면 상단에 붉은 글씨로 안내되며,
    이때는 호기값·계산식 대입값 일부가 표시되지 않습니다. (실행 결과는 정상 확인 가능)
  - OUTPUT 은 TRUE 라인만 표시합니다.
  - 특성코드 사전은 팝업으로 열리므로, 차단된 경우 브라우저에서 팝업을 허용해 주세요.
  - 키보드(↑↓ 라인 이동, Enter 상세, / 검색, Esc 닫기)로도 조작할 수 있습니다.


■ 문의

  화면 오류, 실행 결과 이상, 기능 개선 요청은 아래로 회신 부탁드립니다.
  수배로직설계팀 김영환 M

첨부 : PID 실행 시뮬레이터 화면 사용 매뉴얼 (v1.0)

감사합니다.
```

## 3. 발송 전 확인 사항

- [ ] 접속 경로를 사내 도메인이 포함된 전체 URL 로 교체 (예: `https://<사내도메인>/pid/pidSimulView`)
- [ ] 좌측 사이드바 메뉴에 등록할지 확인 (현재 사이드바에 링크 없음 — 등록 시 본문에 메뉴 위치 추가)
- [ ] 추가 조건(`isfloor` · `floor` · `type`)의 의미와 사용 시점을 매뉴얼 3.1 에 보완할지 확인
- [ ] 첨부 파일을 PDF 로 변환할지 확인 (수신자 중 md 뷰어 미사용자 고려)
- [ ] 문의처(담당자·연락처) 확정
- [ ] 수신자 범위 확정 (설계 담당자 / 유관 부서 포함 여부)
