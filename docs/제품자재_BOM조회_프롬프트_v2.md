## ① 이것만 복사하면 90%는 해결됩니다

```
docs/제품자재_BOM조회_명세서.md 기준, 재현모드 화면동일로
2026년 릴리즈(RLS) 제품 중 자재번호 2117040001 을 쓰는 제품을 조회해줘.
화면 기본 그리드 컬럼 전체, ORDER BY 없음.
조회 후 "적용 연도 / 제품상태 / 적용 조건"을 한 줄로 요약해줘.
```

바꿀 곳은 **2군데**뿐입니다.

| 바꿀 것 | 어떻게 |
|---|---|
| `2026` | 찾을 연도 (**제품 수정일** 기준) |
| `자재번호 2117040001` | 또는 `블록번호 P117040` — **둘 중 하나는 반드시** |

> ⚠️ **연도를 빼면 안 됩니다.** 화면 로직은 연도가 없으면 `2025` 로 조회합니다.

## ② 조건을 더 붙이고 싶을 때

①번 프롬프트 뒤에 **문장만 이어 붙이면** 됩니다. 안 쓰는 건 그냥 안 적으면 됩니다.

| 하고 싶은 것 | 이어 붙일 문구 |
|---|---|
| 자재번호 앞자리로 찾기 | `자재번호는 2117* 로` |
| 특정 블록만 | `블록번호 P117040 조건 추가해서` |
| 기종 한정 | `기종(EL_ATYP) 은 MRL 만` |
| 브랜드 한정 | `브랜드(EL_ABRAND) 는 HDEL 만` |
| 생산거점 한정 | `생산거점(EL_ASPSCD) 은 KR00 만` |
| 관통 호기만 | `관통(EL_ETHRU) 은 Y 만` |
| 적용조건 문구로 | `CMT 에 OPT-A 가 포함된 것만` |
| 자재 SPEC 으로 | `SPEC 에 SS400 이 포함된 것만` |
| 설계일 기준 | `기계구조 최초설계일(EL_ZFDA) 이 20260101 이상인 것만` |
| 치수 조건 | `EL_ECAA 에 1600 이 포함된 것만` |
| 값만 더 보고 싶을 때 | `EL_ECCA, EL_ECHH 값도 컬럼으로 같이 보여줘` |

**예시 (합쳐 쓰기)**

```
docs/제품자재_BOM조회_명세서.md 기준, 재현모드 화면동일로
2026년 릴리즈(RLS) 제품 중 블록번호 P117040 자재를 조회해줘.
기종(EL_ATYP) 은 MRL 만, 기계구조 최초설계일(EL_ZFDA) 이 20260101 이상인 것만.
화면 기본 그리드 컬럼 전체, ORDER BY 없음.
```

## ③ 목적별 복붙 레시피

### 🔍 A. 이 자재, 어디에 쓰이고 있나?

```
docs/제품자재_BOM조회_명세서.md 기준, 재현모드 화면동일로
2026년 릴리즈(RLS) 제품 중 자재번호 2117040001 을 쓰는 제품을 조회해줘.
화면 기본 그리드 컬럼 전체, ORDER BY 없음.

분석도 같이:
- 총 BOM 행 수와 고유 제품 수(COUNT(DISTINCT PE.PRODUCTOUID)) 각각
- 기종 / 브랜드 / 생산거점별 분포 표
- 적용 수량(PART_QTY)이 여러 값으로 섞여 있으면 값별 건수
```

### 🔧 B. 이거 바꾸면 어느 호기가 영향받나? (설계변경 영향도)

```
docs/제품자재_BOM조회_명세서.md 기준, 재현모드 화면동일로
2026년 릴리즈(RLS) 제품 중 블록번호 P117040,
기계구조 최초설계일(EL_ZFDA) 이 20260101 이상인 건을 조회해줘.
화면 기본 그리드 컬럼 전체.

분석도 같이:
- 영향받는 호기번호(PARENTNO) 전체 목록
- 자재별 사용 호기 수 상위 10건 (COUNT(DISTINCT PE.PRODUCTOUID) 기준)
- 호기 1대에만 쓰이는 단발성 자재 목록
```

### 📊 C. 어떤 자재가 제일 많이 쓰이나? (공용화 / 정리 대상)

```
docs/제품자재_BOM조회_명세서.md 기준으로 집계 SQL 을 만들어 실행해줘.
(집계라서 재현모드 화면동일은 적용 안 함)

대상: 2026년 수정 제품, TEST%/Q% 제외, 릴리즈(RLS)만, 블록번호 P117040
집계: 자재번호 / 자재명 / SPEC / 사용 호기 수를 사용 호기 수 많은 순으로
      (사용 호기 수는 COUNT(DISTINCT PE.PRODUCTOUID))

분석도 같이:
- 상위 20건이 전체의 몇 % 인지
- 자재명이 비슷한데 번호가 나뉘어 있으면 공용화 후보로 제시
- 사용 호기 1~2대짜리는 정리 검토 대상으로 별도 목록
```

### 📐 D. 치수 사양별로 어떤 자재를 쓰나?

```

2026년 릴리즈(RLS) 제품 중 자재번호 2117*, 기종(EL_ATYP) MRL 조건으로 조회해줘.
EL_ECAA 에 1600 이 포함된 것만, EL_ECCA / EL_ECCB / EL_ECHH 값도 컬럼으로 보여줘.

분석도 같이:
- 내부가로(EL_ECCA) x 내부세로(EL_ECCB) 조합별로 쓰이는 자재 매트릭스
- 같은 치수 조합인데 자재번호가 다른 케이스 (표준화 후보)
```

## ④ 이것만은 기억하세요 (함정 3개)

| # | 함정 | 대응 |
|---|---|---|
| 1 | **연도를 안 적으면 `2025` 로 조회됩니다** | 프롬프트에 연도를 꼭 쓰고, 결과 요약에서 연도를 확인 |
| 2 | **동적조건에서 `Not Like` 는 항상 0건입니다** (Oracle 문법 오류라 조회가 실패하고 빈 결과가 나옴) | `재현모드: 데이터정확` 으로 요청하고 `NOT LIKE '%값%'` 로 써 달라고 명시 |
| 3 | **`like` 는 `%` 가 자동으로 안 붙습니다** | `1600` 이 아니라 `%1600%` 라고 쓰거나, `"1600 이 포함된"` 이라고 문장으로 요청 |

## ⑤ 결과가 0건이면 여기부터

1. **연도** — *수정일* 기준입니다. 그 해에 수정 이력이 없는 호기는 안 잡힙니다.
2. **릴리즈(RLS)** — 작업중(WIP) 호기가 전부 빠집니다. `상태 조건 빼고 다시` 로 재요청해 보세요.
3. **TEST / Q 호기** — `TEST`, `Q` 로 시작하는 호기번호는 **항상 제외**됩니다. 이 조회로는 못 찾습니다.
4. **사양 조건** — 브랜드·기종 등을 걸면 영업사양이 등록 안 된 호기는 빠집니다.
5. 오류가 나도 **빈 결과**로 보입니다. 조건을 하나씩 빼면서 다시 돌려 보세요.
