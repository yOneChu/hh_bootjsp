제품-자재 Analytics

PLM에 데이터 기반으로 제품-자재 연계 데이터 분석 및 역추적 대시보드

검색 조건

도움말

· PartNo 또는 BlockNo 중 하나는 필수입력 (속도 이슈)

· 자재번호 or BlockNo 입력 시, 해당 자재를 사용하는 모든 현장 역추적 조회합니다.

· TEST, Q호기는 제외됩니다.

· 사용방법: 26300551G0* → Like 검색  |  * 없으면 EQUAL 검색

주요기능

1. 특정 자재가 어떤 제품에 사용되었는지 역추적

2. 다중 조건 필터링을 통한 교차 검색 및 분석

3. 브랜드별 부품 구성 Mix 분석
