제품-자재 Analytics

PLM 데이터 기반으로 제품-자재 연계 데이터를 분석하고 역추적합니다.

도움말 · 검색 조건 안내
  • ·Part No. · Block No. 중 하나, 또는 브랜드 · 생산거점 · 기종 중 하나는 필수 입니다. (속도 이슈 — 조건이 없으면 그 년도 전체 제품을 훑게 됩니다)
  • ·자재번호 or BlockNo 입력 시, 해당 자재를 사용하는 모든 현장을 역추적 조회합니다.
  • ·TEST, Q호기는 제외됩니다.
  • ·사용방법 — 26300551G0* → Like 검색 · * 없으면 EQUAL 검색
  • ·동적 조건 — Value 를 비우면 조건 없이 결과에 그 Key 컬럼만 붙습니다. Like 는 % 를 직접 넣어야 부분일치입니다 (예: %1600%). 엑셀의 Key · Value 두 열을 Key 칸에 붙여넣으면 여러 행이 한 번에 생깁니다.
  • ·조건 칸에서 Enter, 어디서든 Ctrl+Enter 로 분석 · 마지막 조건은 자동으로 다시 채워집니다.
  • ·조건 칸에 입력한 영문 소문자는 자동으로 대문자로 바뀝니다. (예: 26300551g0* → 26300551G0*)
  • ·주요기능 1 — 특정 자재가 어떤 제품에 사용되었는지 역추적
  • ·주요기능 2 — 다중 조건 필터링을 통한 교차 검색 및 분석
  • ·주요기능 3 — 브랜드별 부품 구성 Mix 분석

검색 조건

필수 중 하나, 없으면 대체 중 하나는 꼭 입력 · 영문은 대문자로 자동 변환
1 기본 정보 Part No. · Block No. 중 하나 필수 (없으면 브랜드 · 생산거점 · 기종 중 하나) · 끝에 * 를 붙이면 Like 검색

* 없으면 일치 검색 · * 있으면 Like 검색

Part No. 와 둘 중 하나만 넣어도 됩니다

2 제품 사양 선택 · Part No. / Block No. 가 없으면 브랜드 · 생산거점 · 기종 중 하나는 입력 · 목록에 없으면 직접 입력
3 옵션 선택
4 동적 조건 선택 · Key – 조건 – Value · Value 를 비우면 컬럼만 추가 · 엑셀 두 열 붙여넣기 가능
