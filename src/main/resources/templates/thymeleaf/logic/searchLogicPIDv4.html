PID 상세 분석

SPEC · CON · KEY · VAL · REMARKS 조건으로 로직 PID 데이터를 정밀 조회합니다.

상세 검색

  • 10,000건 이상의 경우 "EXCEL Download"로 받으시기 바랍니다.
  • 현재 Excel 다운로드 시 숫자인식 관련 문제가 있어 Copy로 복사 후, EXCEL에 붙여넣기 하시기 바랍니다.
  • 조건1을 REMARKS로 검색 시 조건2는 사용할 수 없으며, 선택하면 조건2 입력이 자동으로 잠깁니다.
  • 조건2의 값이 공백이라면 해당 조건은 포함되지 않고 조회됩니다.
  • 두 조건의 결합 방식 — 같은 항목쌍: 조건1·2가 같은 번호에서 함께 만족(SPEC1↔VAL1 처럼 짝이 맞는 행) · AND: 각각 만족(번호 달라도 됨) · OR: 둘 중 하나만 만족.
  • PID-03,04,05는 앞 단계가 입력되어야 다음 단계가 열립니다. (ex. PID04만 입력불가(03누락), PID03·05만 입력불가(04누락))
  • PID-GROUP을 EQUAL, LIKE 입력 시 PID03,04,05는 OR 조건, NOT EQUAL, NOT LIKE 입력 시 AND 조건으로 동작합니다.
  • 카드 상단의 최근 검색으로 직전 조건을 다시 불러올 수 있습니다. (이 브라우저에만 저장)

최초 등록 조회

  • 최초 등록 조회는 바로 아래에 접혀 있습니다. 문구를 입력하면 그 문구가 처음 등록된 PID · 버전 · 행(NO) · 등록일 · 로직수정자를 팝업으로 보여줍니다. (검색 문구·PID 모두 필수) 검색 대상은 조회 버튼이 VAL1~VAL20
  • 전체컬럼대상조회 버튼이 SPEC1~30 · CON1~30 · KEY1~20 · VAL1~20 입니다. 검색 결과 표의 셀을 더블클릭하면 그 값과 해당 행의 PID로 바로 조회됩니다. (VAL 대상)
  • 로직수정자는 해당 버전을 등록·수정한 담당자 이름입니다. 요약 타일과 같은 버전에서 걸린 행 표, 결과 복사(엑셀 붙여넣기)에 모두 포함됩니다. (사용자 정보가 없는 예전 데이터는 — 로 표시됩니다)
최초 등록 조회 문구가 처음 등록된 PID · 버전 · 행 · 날짜 · 로직수정자를 팝업으로 확인합니다
기능 입력한 PID 안에서 그 문구가 있는 가장 먼저 등록된 버전을 찾습니다.
조회 버튼 VAL1~VAL20 컬럼을 대상으로 분석합니다.
전체컬럼대상조회 SPEC1~30 · CON1~30 · KEY1~20 · VAL1~20을 대상으로 분석합니다.

검색 문구와 PID는 둘 다 필수이며, 결과에는 그 버전을 등록한 로직수정자가 함께 표시됩니다.
