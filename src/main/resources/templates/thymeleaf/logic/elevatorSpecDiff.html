영업사양 비교

두 호기의 영업사양 특성값을 대조하여 서로 다른 항목만 상단에 모아 보여줍니다.

💡 도움말 · 사용 안내
  • ·호기-01, 호기-02 모두 필수입력 입니다.
  • ·조회 후 차이점 요약 영역에 서로 다른 사양만 구분별로 묶어서 표시됩니다.
  • ·구분 — 값 상이(양쪽 값이 다름) · 호기 1만 존재 · 호기 2만 존재
  • ·사양값은 PLM ELV_INFO 원본을 직접 읽어와 코드값을 표시값으로 변환한 결과입니다. (findElvSearch 와 동일 경로)
  • ·그룹 — 기본정보(MD$ 컬럼) · 영업사양(한글 특성명이 정의된 코드) · 기타
  • ·값 비교는 앞뒤 공백·대소문자를 무시하며, 빈 값 / - / null 은 모두 "없음" 으로 취급합니다.
  • ·두 호기 모두 값이 비어있는 사양과 내부키 컬럼(VF$·ID$)은 비교 대상에서 제외됩니다.
  • ·하단 전체 비교 결과에서 차이만 보기 스위치로 동일 항목을 숨길 수 있습니다.
  • ·입력창에서 Enter 키로 바로 조회됩니다.
