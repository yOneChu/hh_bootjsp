1실행 조건

공사값으로 한 번 실행해서, 실행된 PID 의 SPEC 열 중 영업사양 코드만 아래에 표시합니다.
추출 범위
전처리 PID 는 실행만 하고 SPEC 은 뽑지 않습니다.
SPEC 코드 전체-추출 전
영업사양 코드-값 입력 대상
영업사양 아님-PID 내부 변수 · 결과값
값 변경-공사값과 다르게 입력
공사값 없음-공사에 값이 비어 있음

2영업사양 값 입력

입력칸을 비우면 공사값 그대로 실행합니다. CON 값을 누르면 바로 채워집니다.
# 특성코드 사양명 사용 라인 공사 현재값 실행할 값 상태 되돌리기
아직 추출한 영업사양이 없습니다위에서 공사번호와 PID 를 입력하고 [영업사양 추출] 을 누르세요.
영업사양이 아닌 SPEC 0개 — 특성코드 사전에 없는 코드 (PID 실행 중에 계산되는 내부 변수 / 결과값)라 값을 지정하지 않습니다.

3실행 결과

영업사양을 바꾸지 않고 최신 버전으로 실행한 결과와, 영업사양을 바꿔 실행한 결과를 비교합니다.
아직 실행하지 않았습니다 영업사양 값을 입력한 뒤 아래 [지정값으로 실행] 을 누르세요.
