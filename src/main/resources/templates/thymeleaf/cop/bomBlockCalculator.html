2일자별 영업사양 값

자재수배 PID · 블럭 PID · CALL 하위 PID 의 SPEC 열 중 영업사양 코드만 보여줍니다. 칸을 비우면 공사값 그대로 계산합니다.
아직 추출한 영업사양이 없습니다호기와 블럭 PID, 비교 일자를 입력하고 [영업사양 추출] 을 누르세요.
영업사양이 아닌 SPEC 0개 — 특성코드 사전에 없는 코드 (PID 내부 변수 / 결과값)라 값을 지정하지 않습니다.

3일자별 자재 · 수량 비교

일자마다 수배되는 자재(PICK 값)와 블럭 PID 결과(QTY 등)를 비교합니다. 일자 사이에 다른 값은 노란색으로 표시합니다.
