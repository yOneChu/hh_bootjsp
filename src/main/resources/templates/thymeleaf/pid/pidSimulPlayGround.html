PID 를 불러오면 확인
CALL 하위 PID 와 전처리 PID 는 DB 최신 버전으로 실행됩니다. 수정본은 불러온 PID 에만 적용됩니다.
불러온 PID 없음
범례
  • TRUE : 조건 만족 라인
  • FALSE : 조건 불만족 라인
  • 미실행 : GOTO / STOP 으로 건너뜀
  • ✓ 조건 일치 (SPEC 값 = CON)
  • ✗ 조건 불일치
  • 수정한 칸 (마우스를 올리면 DB 원본 값)
  • 새로 추가한 라인
  • 디버거 현재 단계
단축키
  • Ctrl+Enter실행
  • Ctrl+S임시 저장 (브라우저)
  • F10다음 단계
  • Shift+F10이전 단계
  • Ctrl+Z / Y되돌리기 / 다시 실행
  • 오른쪽 클릭라인 추가 · 복제 · 삭제
  • 행 번호 끌기라인 순서 바꾸기
  • 결과 표 더블클릭라인 상세 보기

PID 를 불러와 DB 저장 없이 바로 고쳐 보세요

고친 로직은 이 화면에서 실행할 때만 쓰이고 DB 에는 저장되지 않습니다.

  1. 1위에서 PID 와 버전을 고르고 불러오기 를 누릅니다.
  2. 2표에서 SPEC / CON / KEY / VAL 을 고칩니다. 오른쪽 클릭으로 라인을 추가 · 복제 · 삭제할 수 있습니다.
  3. 3공사번호를 넣고 실행(Ctrl+Enter)하면 라인마다 TRUE / FALSE 와 그 시점의 값이 표시됩니다. 실시간 실행을 켜 두면 고칠 때마다 자동으로 다시 실행합니다.

실행하면 라인별 결과가 여기에 표시됩니다.
