공사 영업사양으로 PID 로직을 라인 단위로 실행해 봅니다

PLM DB 의 PID 로직과 공사 영업사양을 그대로 읽어 실행하고, 라인마다 조건 비교 결과를 보여줍니다. DB 에는 쓰지 않습니다.

  1. 1공사번호와 PID 를 입력합니다. 버전을 고르지 않으면 최신 버전으로 실행합니다.
  2. 2실행(Enter)을 누르면 라인마다 TRUE / FALSE 와 조건별 일치 여부가 표시됩니다.
  3. 3라인을 누르면 오른쪽에 상세가, CALL 한 하위 PID 는 상단에서 버전을 바꿔 다시 실행할 수 있습니다.
